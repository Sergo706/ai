This documentation site (`https://ai.riavzon.com`) publishes machine-readable endpoints alongside the web UI so coding assistants, IDE extensions, and autonomous agents can discover, install, and query `@riavzon/ai` documentation directly without HTML scraping.

## Choose an integration path

Pick the interface that matches how your tool or agent consumes external documentation:

| Integration | Endpoint | Format | Best For |
| --- | --- | --- | --- |
| **Agent Skills** | `/.well-known/skills/index.json` | JSON catalog + Markdown `SKILL.md` | Teaching coding agents `@riavzon/ai` workflows, API rules, and pitfalls on demand |
| **MCP Server** | `/mcp` | Streamable HTTP (Model Context Protocol) | Letting IDE assistants (`Cursor`, `VS Code`, `Claude Code`) search and fetch live doc pages |
| **MCP Server Card** | `/.well-known/mcp/server-card.json` | JSON metadata | Zero-config MCP transport and tool discovery |
| **`llms.txt`** | `/llms.txt` | Plain-text Markdown index | Compact table of contents for LLM context windows |
| **`llms-full.txt`** | `/llms-full.txt` | Consolidated Markdown | Ingesting the entire documentation site in one fetch |
| **Raw Markdown** | `/raw/<path>.md` or `Accept: text/markdown` | `text/markdown` | Fetching any single guide or the API reference cleanly |
| **Markdown Sitemap** | `/sitemap.md` | Markdown link list | Enumerating every published documentation route |
| **OpenAPI 3.1** | `/openapi.json` | OpenAPI JSON | Programmatic discovery of every agent-facing route and MCP endpoint |
| **API Catalog** | `/.well-known/api-catalog` | `application/linkset+json` (RFC 9727) | Standards-based discovery linking OpenAPI (`service-desc`) and Skills (`service-doc`) |

## Install Agent Skills

Agent Skills follow the [Agent Skills specification](https://agentskills.io/specification) and the Cloudflare Agent Skills Discovery RFC (`/.well-known/skills/`). Install both `@riavzon/ai` skills into Claude Code, Cursor, Windsurf, GitHub Copilot, and other compatible agents with one command:

```bash [Terminal]
npx skills add https://ai.riavzon.com
```

### Review published skills

This site publishes two focused, compiler-verified skills so agents only load the context relevant to the task at hand:

| Skill Name | Scope & When to Activate | Bundled Reference Files |
| --- | --- | --- |
| `riavzon-ai` | Core runtime setup (`configuration()`), `createAgent()`, `ToolSpec`s, all eight built-in tools, MCP servers, RAG chunking/embeddings/vector search, SSE adapters, `TraceExtension`, and lazy peer dependencies | `references/tools-and-mcp.md`, `references/rag-and-storage.md`, `references/streaming-and-http.md` |
| `riavzon-ai-workflows-and-runs` | Multi-stage `AgenticWorkflowLoop`, all six adapters, `WorkflowBudgets`, checkpoints, `runWorkflow<TData, TMeta>()`, `registerRunResumer()`, `startRuns()`, Redis Streams replay (`streamFromRun` / `streamFromStore`), `workflowStreamWithRegistry()`, and `RUNS_*` tuning | `references/workflow-adapters-and-checkpoints.md`, `references/run-system-and-reattach.md` |

### Inspect skill endpoints directly

Fetch the discovery catalog or individual skill files over HTTP from any CI script or custom agent loader:

```bash [Terminal]
# 1. List all published skills and their bundled files
curl -s https://ai.riavzon.com/.well-known/skills/index.json

# 2. Download core runtime skill
curl -s https://ai.riavzon.com/.well-known/skills/riavzon-ai/SKILL.md

# 3. Download workflows & durable runs skill
curl -s https://ai.riavzon.com/.well-known/skills/riavzon-ai-workflows-and-runs/SKILL.md
```

::tip
Combine **Agent Skills** with **`llms.txt`** or **MCP**: skills teach agents exact `@riavzon/ai` conventions, peer requirements, and pitfalls up front, while MCP and `/raw/*.md` let them look up individual pages or full API signatures when needed.
::

## Connect the MCP server

The documentation site exposes a Streamable HTTP Model Context Protocol server at `https://ai.riavzon.com/mcp` along with its Server Card at `https://ai.riavzon.com/.well-known/mcp/server-card.json`.

### Available MCP tools

| Tool | Arguments | Returns |
| --- | --- | --- |
| `list-pages` | `locale?: string` | Array of `{ title, path, description, locale, url }` for all documentation pages |
| `get-page` | `path: string` (for example `/agents` or `/getting-started/quickstart`) | Full page object `{ title, path, description, content, url }` containing clean Markdown |

### Configure your client

Choose your editor or runtime below to register the `@riavzon/ai` documentation MCP server:

::code-group
```json [.cursor/mcp.json]
{
  "mcpServers": {
    "riavzon-ai": {
      "url": "https://ai.riavzon.com/mcp"
    }
  }
}
```

```json [.vscode/mcp.json]
{
  "servers": {
    "riavzon-ai": {
      "type": "http",
      "url": "https://ai.riavzon.com/mcp"
    }
  }
}
```

```bash [Claude Code]
claude mcp add --transport http riavzon-ai https://ai.riavzon.com/mcp
```

```ts [src/docs-agent.ts]
import { createAgent } from "@riavzon/ai";

export const docsAssistant = await createAgent({
  model: { model: "gpt-4.1-mini" },
  systemInstructions: "Answer @riavzon/ai questions using the live documentation MCP tools.",
  tools: {
    mcp: [
      {
        namespace: "riavzon_docs",
        url: "https://ai.riavzon.com/mcp",
      },
    ],
  },
});
```
::

## Fetch llms.txt and raw Markdown

Use static Markdown endpoints when pasting docs into prompts, feeding RAG pipelines, or querying pages from terminal scripts without an MCP client.

### Read index and full exports

- **`https://ai.riavzon.com/llms.txt`** — Curated section overview with descriptions and canonical links to every major subsystem.
- **`https://ai.riavzon.com/llms-full.txt`** — Every documentation page concatenated into a single Markdown file for whole-corpus ingestion or long-context prompts.
- **`https://ai.riavzon.com/sitemap.md`** — Concise Markdown list of all published documentation routes.

### Request individual pages as Markdown

Append `.md` under `/raw/` for any documentation path, or send `Accept: text/markdown` to any documentation URL:

```bash [Terminal]
# Direct raw Markdown route
curl -s https://ai.riavzon.com/raw/getting-started/quickstart.md
curl -s https://ai.riavzon.com/raw/api-reference.md

# Content negotiation with Accept: text/markdown
curl -sL -H "Accept: text/markdown" https://ai.riavzon.com/agents
```

## Discover endpoints with OpenAPI and well-known routes

Automated agents and API discovery clients can bootstrap every endpoint from standard RFC 8615 / RFC 9727 routes without hardcoding URLs:

| Route | Standard / Media Type | Purpose |
| --- | --- | --- |
| `/.well-known/api-catalog` | RFC 9727 (`application/linkset+json`) | Advertises `/openapi.json` (`rel="service-desc"`) and published skills (`rel="service-doc"`) |
| `/openapi.json` | OpenAPI 3.1 (`application/json`) | Full schema of documentation, raw Markdown, skills, and MCP routes |
| `/.well-known/mcp/server-card.json` | MCP Server Card (`application/json`) | Advertises `/mcp` transport type, endpoint URL, and public tool list |
| `/.well-known/skills/index.json` | Agent Skills Discovery (`application/json`) | Lists available skills, descriptions, and relative file paths |
| `/robots.txt` | Robots + `Content-Signal` | Explicitly permits search, AI input, and indexing (`search=yes, ai-train=yes, ai-input=yes`) |

Inspect the catalog and response `Link` headers with `curl`:

```bash [Terminal]
# Inspect RFC 9727 API catalog
curl -s https://ai.riavzon.com/.well-known/api-catalog

# Inspect OpenAPI 3.1 document
curl -s https://ai.riavzon.com/openapi.json

# Inspect MCP Server Card
curl -s https://ai.riavzon.com/.well-known/mcp/server-card.json
```
