This guide walks you from a fresh Node.js project to a working streaming agent backed by SQLite, built-in tools, a custom typed tool, and structured JSON extraction.

## Build a streaming agent in five minutes

::steps

### Install dependencies

Install `@riavzon/ai`, `openai`, the SQLite peers, and `mathjs` (for the built-in `calculator` tool).

::code-group

```bash [npm]
npm install @riavzon/ai openai better-sqlite3 sqlite-vec mathjs zod
```

```bash [pnpm]
pnpm add @riavzon/ai openai better-sqlite3 sqlite-vec mathjs zod
```

```bash [yarn]
yarn add @riavzon/ai openai better-sqlite3 sqlite-vec mathjs zod
```

```bash [bun]
bun add @riavzon/ai openai better-sqlite3 sqlite-vec mathjs zod
```

::

### Initialize the runtime

Call `configuration()` once at startup before invoking any agent or database helper. This example creates a local SQLite database with automatic migrations and uses the default in-memory cache.

```ts [src/ai.ts]
import OpenAI from "openai";
import { configuration } from "@riavzon/ai";

export async function initAi() {
  await configuration({
    db: "./data/quickstart.db",
    openAiConfig: new OpenAI({
      apiKey: process.env.OPENAI_API_KEY,
    }),
    embeddingConfig: {
      dimensions: 1536,
      matchingModel: "text-embedding-3-small",
      retrievalModel: "text-embedding-3-small",
    },
  });
}
```

### Create an agent with tools

Use `createAgent()` to combine built-in tools (`tools.common`) with your own `ToolSpec` definitions (`tools.specs`). Each `ToolSpec` builds a fresh handler per turn via `make(ctx)`, giving the tool safe access to the current `userId`, `conversationId`, and custom `meta`.

```ts [src/agent.ts]
import { createAgent, type ToolSpec } from "@riavzon/ai";

interface AppMeta {
  orgId: string;
}

const lookupOrderTool: ToolSpec<AppMeta> = {
  name: "lookup_order",
  definitions: {
    type: "function",
    function: {
      name: "lookup_order",
      description: "Look up an order status by its order ID.",
      parameters: {
        type: "object",
        properties: {
          orderId: {
            type: "string",
            description: "Order identifier, e.g. ORD-1042",
          },
        },
        required: ["orderId"],
      },
    },
  },
  cache: { ttl: 300, scoped: true },
  maxCalls: 5,
  make: (ctx) => async (args) => {
    const orderId = String(args.orderId ?? "");
    return {
      orderId,
      orgId: ctx.meta?.orgId,
      requestedBy: ctx.userId,
      status: "shipped",
      etaDays: 2,
    };
  },
};

export async function buildSupportAgent() {
  return await createAgent<AppMeta>({
    model: {
      model: "gpt-4o-mini",
      temperature: 0.2,
      tools: {
        maxRounds: 6,
      },
    },
    systemInstructions:
      "You are a concise support assistant. Use tools for calculations and order lookups.",
    tools: {
      common: ["calculator", "get_current_datetime"],
      specs: [lookupOrderTool],
    },
    conversation: {
      persist: true,
    },
    compaction: {
      temperature: 0.2,
      maxTokens: 1024,
      tokenThreshold: 12_000,
      keepRecentMessages: 20,
    },
  });
}
```

### Run a turn or stream over SSE

Call `agent.complete()` for a buffered response, `agent.chat()` to iterate typed SSE frames or pipe them straight into an HTTP `Response`, or pass `json: { validate: true, schema }` to `agent.complete()` for schema-validated structured output.

::tabs
:::tabs-item{label="Buffered turn (complete)" icon="i-lucide-message-square"}

```ts [src/run-complete.ts]
import { initAi } from "./ai";
import { buildSupportAgent } from "./agent";

await initAi();
const agent = await buildSupportAgent();

const turn = await agent.complete({
  message:
    "Check order ORD-1042 and calculate 3 items at $49.99 with 8.5% tax.",
  userId: "user_42",
  meta: { orgId: "acme" },
});

console.log("Conversation:", turn.conversationId);
console.log("Tools used:", turn.toolsUsed);
console.log("Answer:\n", turn.text);

await agent.close();
```

:::

:::tabs-item{label="HTTP SSE route (chat)" icon="i-lucide-radio"}

```ts [src/routes/chat.ts]
import { framesToStream, setSseHeaders } from "@riavzon/ai";
import { buildSupportAgent } from "../agent";

const agentPromise = buildSupportAgent();

export async function POST(req: Request): Promise<Response> {
  const body = (await req.json()) as {
    message: string;
    userId: string;
    conversationId?: number;
  };

  const agent = await agentPromise;
  const controller = new AbortController();

  const chat = await agent.chat({
    message: body.message,
    userId: body.userId,
    conversationId: body.conversationId,
    meta: { orgId: "acme" },
    signal: controller.signal,
  });

  const stream = framesToStream(chat.frames, {
    onCancel: () => controller.abort(),
  });

  return new Response(stream, {
    headers: setSseHeaders(),
  });
}
```

:::

:::tabs-item{label="Structured JSON" icon="i-lucide-braces"}

```ts [src/run-json.ts]
import { z } from "zod";
import { initAi } from "./ai";
import { buildSupportAgent } from "./agent";

await initAi();
const agent = await buildSupportAgent();

const TicketSchema = z.object({
  orderId: z.string(),
  priority: z.enum(["low", "medium", "high"]),
  summary: z.string(),
});

const { structured: ticket } = await agent.complete({
  message:
    "Customer says order ORD-1042 arrived damaged and needs an urgent replacement.",
  userId: "user_42",
  json: {
    validate: true,
    schema: TicketSchema,
    schemaName: "support_ticket",
    maxRetries: 2,
  },
});

console.log(ticket?.priority, ticket?.orderId);
await agent.close();
```

## Call low-level exports directly

If you already have your own AI client or custom orchestration loop, you do not need `createAgent()`. You can invoke the underlying primitives directly:

```ts [src/custom-loop.ts]
import OpenAI from "openai";
import {
  buildToolRegistry,
  executeToolLoop,
  resolveCommonTools,
  type AgentEvent,
} from "@riavzon/ai";

const client = new OpenAI({ apiKey: process.env.OPENAI_API_KEY });
const specs = resolveCommonTools(["calculator", "get_current_datetime"]);
const registry = buildToolRegistry({ userId: "user_42" }, specs);

const onEvent = (event: AgentEvent) => {
  if (event.type === "chunk") process.stdout.write(event.text);
  if (event.type === "tool_start") console.error(`\n[tool] ${event.name}`);
};

// Pass `emit` for live tool-round events AND drain the generator for fallback synthesis events.
for await (const event of executeToolLoop({
  client,
  model: "gpt-4o-mini",
  stream: true,
  emit: onEvent,
  messages: [
    { role: "system", content: "You are a precise analyst." },
    {
      role: "user",
      content: "What is 18.5% of 4280, and what UTC time is it now?",
    },
  ],
  availableTools: Object.values(registry.definitions),
  handlers: registry.handlers,
  tools: { temperature: 0.1, maxTokens: 2048, maxRounds: 5, maxCalls: 10 },
  chat: { temperature: 0.3, maxTokens: 4096 },
  toolConcurrency: registry.toolConcurrency,
  toolStreaming: registry.toolStreaming,
})) {
  onEvent(event);
}
```
