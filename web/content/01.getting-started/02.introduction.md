`@riavzon/ai` is an embeddable TypeScript runtime for AI agents, tool execution, Model Context Protocol (MCP) integrations, retrieval-augmented generation (RAG), multi-stage workflows, and crash-resilient durable runs. It runs directly inside your Node.js service without opening ports, mounting HTTP routes, or injecting hidden system prompts.

You control your HTTP framework, authentication, database lifecycle, and raw OpenAI-compatible wire payloads. Every layer — from the high-level `createAgent()` wrapper down to `executeToolLoop()`, `AgenticWorkflowLoop`, SSE frame helpers, database models, and standalone utilities — is exported from the single package entry point `@riavzon/ai`.

## Design philosophy

The runtime separates orchestration from application ownership so you can adopt the full agent stack or cherry-pick individual primitives inside an existing AI client.

## Architecture layers

Every module in `@riavzon/ai` sits on top of clean, directly importable building blocks. You never have to adopt the full stack to benefit from one part of it.

| Layer | High-level abstraction | Low-level building blocks |
| --- | --- | --- |
| **Agents** | `createAgent()` (`chat`, `complete`, `close`) | `executeToolLoop()`, `buildToolRegistry()`, `resolveConversation()`, `compactHistory()` |
| **Tools & MCP** | `resolveCommonTools()`, `createMcpToolset()` | `ToolSpec`, `withToolCache()`, `limitTool()`, `trackTool()`, `toolError()`, `buildToolDefinitions()` |
| **Streaming & Chat** | `framesToStream()`, `workflowStream()`, `runAgentStream()` | `frame()`, `encode()`, `setSseHeaders()`, `staticReplyStream()`, `createEventSink()`, `TraceCollector`, `createRequestAbort()` |
| **RAG** | `prepareScrape()`, `saveUploadedScrappedFile()`, `filterAdaptiveChunks()` | `generateEmbedding()`, `generateMatchingEmbedding()`, `fetchRelevantChunks()`, `searchDbDocs()`, `chunkByTokens()` |
| **Workflow Agents** | `AgenticWorkflowLoop` | `WorkflowState`, `WorkflowBudgets`, stage adapters, `WorkflowAbortedError` |
| **Run System** | `startRuns()`, `runWorkflow()`, `retryRun()` | `claimRun()`, `startLeaseHeartbeat()`, `pumpRun()`, `streamFromRun()`, `streamFromStore()`, `tailRun()`, `checkpoint()` |
| **Database & Models** | Automatic Kysely migrations in `configuration()` | `toJson()`, `fromJson()`, `toVec()`, `getDistance()`, `timestamp()`, and all `models/*` helpers |
| **Utilities** | `llmSchemaParser()`, `readGeneratedFile()` | `chunkByTokens()`, `estimateMessagesTokens()`, `jsonToMarkdown()`, `readPdf()`, `createPdf()`, `generateStyledSpreadsheet()`, `calculateCosineSimilarity()` |

::note
`@riavzon/ai` exposes a single package entry point. Import every function, class, and type directly from `"@riavzon/ai"`.
::

## What the package owns vs. what you own

Understanding this boundary makes integration predictable across any server stack (Express, Fastify, Hono, Nitro/Nuxt, Next.js, or standalone workers).

- **`@riavzon/ai` owns**: database schema migrations, OpenAI tool-calling loops, tool caching and concurrency limits, MCP session management, history compaction, vector similarity queries, lease heartbeats, crash recovery sweeps, and SSE frame encoding.
- **Your application owns**: HTTP routes, request authentication and authorization, rate limiting, `Response` creation, file download endpoints, prompt engineering, and OpenAI-compatible provider selection.
