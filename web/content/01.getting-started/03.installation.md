`@riavzon/ai` keeps its core install footprint small by declaring heavy runtime integrations as optional peer dependencies. Every peer is loaded lazily on first use through an internal peer loader, so a project that only needs chat and SQLite never installs PostgreSQL drivers, spreadsheet libraries, or the MCP client.

## Install the core package

Install `@riavzon/ai` together with `openai` (required for chat completions and embeddings) using your preferred package manager.

::code-group
```bash [npm]
npm install @riavzon/ai openai
```

```bash [pnpm]
pnpm add @riavzon/ai openai
```

```bash [yarn]
yarn add @riavzon/ai openai
```

```bash [bun]
bun add @riavzon/ai openai
```
::

::note
Core runtime dependencies (`kysely`, `zod`, `pdf-parse`, and `@riavzon/utils`) are installed automatically with `@riavzon/ai`.
::

## Choose a database peer

`@riavzon/ai` supports both SQLite (via `better-sqlite3` + `sqlite-vec`) and PostgreSQL (via `pg` + `pgvector`). Install the peers for the dialect you pass to `configuration({ db })`.

::tabs
  :::tabs-item{label="SQLite (local & single-node)" icon="i-lucide-file-spreadsheet"}
  Install `better-sqlite3` and `sqlite-vec` for zero-daemon local storage with vector similarity search:

  ```bash [Terminal]
  npm install better-sqlite3 sqlite-vec
  ```

  When `configuration()` receives a file path string such as `"./data/app.db"`, it enables WAL mode (`journal_mode = WAL`), `synchronous = NORMAL`, `foreign_keys = ON`, loads the `sqlite-vec` extension, and runs migrations automatically.
  :::

  :::tabs-item{label="PostgreSQL (production & multi-replica)" icon="i-lucide-database"}
  Install `pg` (and `@types/pg` for TypeScript) when connecting to PostgreSQL with the `pgvector` extension enabled:

  ```bash [Terminal]
  npm install pg
  npm install -D @types/pg
  ```

  Pass a `pg.Pool` instance to `configuration({ db: pool })`. The initial migration runs `CREATE EXTENSION IF NOT EXISTS vector` and creates HNSW cosine indexes on `document_chunks.embedding` and `messages.embedding`.
  :::
::

## Install optional feature peers

Install only the peers required for the features and built-in tools you enable. If you call a feature without its peer installed, `@riavzon/ai` throws a clear error naming the missing package.

| Peer package(s) | Required for | When to install |
| --- | --- | --- |
| `ioredis` | Distributed caching, cross-replica run streams (`streamFromStore`, `tailRun`), `pdf_creator`, and `create_styled_spreadsheet` | Multi-replica deployments or generated file tools |
| `mathjs` | Built-in `calculator` tool | Enabling `"calculator"` in `commonTools` or calling `calculator()` |
| `easy-currencies` | Built-in `currencies_convertor` tool | Enabling `"currencies_convertor"` or calling `currenciesConvertor()` |
| `exceljs` | Built-in `create_styled_spreadsheet` tool, `readXlsxToMarkdown()`, `readCsvToMarkdown()`, `generateStyledSpreadsheet()` | Creating or reading XLSX/CSV files and spreadsheet attachments |
| `pdf-lib` and `@pdf-lib/fontkit` | Built-in `pdf_creator` tool and `createPdf()` utility | Generating or modifying PDF documents with Unicode font support |
| `@steipete/summarize-core` | Built-in `extractor` tool | Extracting and summarizing web pages or media URLs |
| `@modelcontextprotocol/client` | `createMcpToolset()` and `tools.mcp` in `createAgent()` | Connecting to Streamable HTTP MCP servers |
| `@huggingface/transformers` | Optional `PreTrainedTokenizer` argument to `chunkByTokens()`, `countTokens()`, and `prepareScrape()` | Exact tokenizer-based chunk sizing instead of the built-in character heuristic |

```bash [Install all optional peers]
npm install ioredis mathjs easy-currencies exceljs pdf-lib @pdf-lib/fontkit @steipete/summarize-core @modelcontextprotocol/client @huggingface/transformers
```

## Verify TypeScript and runtime requirements

`@riavzon/ai` ships dual ESM (`dist/main.mjs`) and CJS (`dist/main.cjs`) bundles with full `.d.ts` and `.d.cts` type declarations.

- **Node.js**: Node.js 20 or later is recommended (uses global `fetch`, `ReadableStream`, `AbortSignal.any`, and `crypto.randomUUID`).
- **Single entry point**: Import every symbol from `"@riavzon/ai"`. Subpath imports such as `"@riavzon/ai/agents"` are not exported.

```ts [src/setup.ts]
import OpenAI from "openai";
import { configuration, createAgent } from "@riavzon/ai";

await configuration({
  db: "./data/app.db",
  openAiConfig: new OpenAI({ apiKey: process.env.OPENAI_API_KEY }),
  embeddingConfig: {
    dimensions: 1536,
    matchingModel: "text-embedding-3-small",
    retrievalModel: "text-embedding-3-small",
  },
});
```

::warning
Call and `await configuration(...)` once during application startup before calling `createAgent()`, database models, cache helpers, or `startRuns()`. Importing the package before calling `configuration()` is completely safe because database and storage clients initialize lazily.
::
