This page assembles a complete, runnable `AgenticWorkflowLoop` using real `@riavzon/ai` primitives with no stubbed helpers:

- **`localKnowledge`**: queries your vector store via `generateMatchingEmbedding()` + `fetchRelevantChunks()`
- **`externalDiscovery`**: runs a cancellable web-search HTTP call honoring `ctx.signal`
- **`targetExecutor`**: fetches live pages with `extractor(false)`, chunks/embeds with `prepareScrape()`, deduplicates relevant chunks across pages with `filterAdaptiveChunks()`, and appends accepted snippets to `state.appendEvidence()`
- **`evaluator`**: calls your OpenAI client via `aiClients()` and parses a strict Zod verdict with `llmSchemaParser()`
- **`critic`**: reviews accumulated evidence before final synthesis and can request follow-up external intents when coverage gaps remain
- **`finalAnswer`**: synthesizes a typed, citation-backed `ResearchReport` with `llmSchemaParser()`
- **Durable execution + SSE**: runs inside `runWorkflow()` + `workflowStreamWithRegistry()` + `runProgressFrames()` so clients stream live progress and can reattach or resume across crashes

## Define schemas and domain types

Start by defining Zod schemas for the three LLM stages (`evaluator`, `critic`, and `finalAnswer`) plus the domain types shared across adapters:

```ts [src/workflows/researchSchemas.ts]
import { z } from "zod";

export const EvaluatorVerdictSchema = z.object({
  isSufficient: z.boolean(),
  nextIntents: z.array(z.string().min(2)).max(4),
});

export const CriticVerdictSchema = z.object({
  approved: z.boolean(),
  notes: z.string().optional(),
  followUpIntents: z.array(z.string().min(2)).max(3).optional(),
});

export const ResearchReportSchema = z.object({
  executiveSummary: z.string(),
  keyFindings: z.array(
    z.object({
      claim: z.string(),
      evidence: z.string(),
      sourceUrlOrTitle: z.string(),
    }),
  ),
  caveats: z.array(z.string()),
});

export type ResearchReport = z.infer<typeof ResearchReportSchema>;

export interface SearchTarget {
  url: string;
  title: string;
}

export interface ScrapedArtifact {
  url: string;
  title: string;
  acceptedChunks: number;
}
```

## Implement the structured LLM helper

Each LLM stage uses `aiClients()` plus `llmSchemaParser()` so malformed JSON or missing fields are automatically repaired against the Zod schema:

```ts [src/workflows/structuredCall.ts]
import type { ChatCompletionMessageParam } from "openai/resources";
import { aiClients, getConfiguration, llmSchemaParser } from "@riavzon/ai";
import { z } from "zod";

export async function runStructuredStage<S extends z.ZodType>(opts: {
  stageName: string;
  model: string;
  schema: S;
  messages: ChatCompletionMessageParam[];
  signal?: AbortSignal;
}): Promise<z.output<S>> {
  const aiClient = aiClients();
  const logger = getConfiguration().logger;

  const initial = await aiClient.chat.completions.create(
    {
      model: opts.model,
      temperature: 0.1,
      response_format: { type: "json_object" },
      messages: opts.messages,
    },
    { signal: opts.signal },
  );

  return llmSchemaParser(
    opts.schema,
    initial,
    {
      agent: opts.stageName,
      messages: opts.messages,
      schemaName: opts.stageName,
      maxRetries: 2,
      retry: (req) =>
        aiClient.chat.completions.create(
          {
            model: opts.model,
            temperature: 0,
            messages: req.messages,
            response_format: req.response_format ?? { type: "json_object" },
          },
          { signal: opts.signal },
        ),
    },
    logger,
  );
}
```

## Wire all six adapters into `AgenticWorkflowLoop`

Now combine local RAG retrieval, external discovery, adaptive web extraction, LLM evaluation, critic review, and final synthesis into one workflow runner compatible with `runWorkflow()`:

```ts [src/workflows/runResearchWorkflow.ts]
import {
  AgenticWorkflowLoop,
  checkpoint,
  extractor,
  fetchRelevantChunks,
  filterAdaptiveChunks,
  generateMatchingEmbedding,
  parseCheckpoint,
  prepareScrape,
  type AgenticWorkflowConfig,
  type RelevantChunk,
  type WorkflowBudgets,
  type WorkflowCheckpoint,
  type WorkflowExecution,
  type WorkflowRunContext,
  type WorkflowStage,
} from "@riavzon/ai";
import {
  CriticVerdictSchema,
  EvaluatorVerdictSchema,
  ResearchReportSchema,
  type ResearchReport,
  type ScrapedArtifact,
  type SearchTarget,
} from "./researchSchemas";
import { runStructuredStage } from "./structuredCall";

const RESEARCH_BUDGETS: WorkflowBudgets = {
  maxLocalRounds: 3,
  maxExternalRounds: 4,
  localBatchSize: 8,
  maxIntentsPerRound: 3,
  maxTargetsPerIntent: 4,
  maxEvaluatorItems: 24,
  maxConsecutiveInsufficientLocalBatches: 2,
  maxSkippedExternalRounds: 2,
  maxRepeatedIntentRounds: 2,
  maxDiscoveryFailuresPerIntent: 2,
};

const MODEL = process.env.RESEARCH_MODEL ?? "gpt-4o-mini";

async function searchWeb(
  intent: string,
  signal?: AbortSignal,
): Promise<SearchTarget[]> {
  // Replace with your preferred search API (Tavily, Brave, Serper, SearXNG, etc.)
  const res = await fetch(
    `${process.env.SEARCH_API_URL!}?q=${encodeURIComponent(intent)}&limit=5`,
    {
      headers: { Authorization: `Bearer ${process.env.SEARCH_API_KEY!}` },
      signal,
    },
  );
  if (!res.ok) throw new Error(`Search API returned HTTP ${res.status}`);
  const data = (await res.json()) as {
    results?: { url: string; title: string }[];
  };
  return (data.results ?? []).map((r) => ({ url: r.url, title: r.title }));
}

export interface ResearchWorkflowMeta {
  urls: string[];
}

export async function executeResearchWorkflow(
  query: string,
  runCtx: WorkflowRunContext,
  userId?: string,
): Promise<WorkflowExecution<ResearchReport, ResearchWorkflowMeta>> {
  const queryVector = await generateMatchingEmbedding(query);
  const extract = extractor(false);
  const accumulatedMatchingVectors: number[][] = [];

  // Restore durable checkpoint if this run is resuming after a crash or retry
  const saved = parseCheckpoint<WorkflowCheckpoint, WorkflowStage>(
    await runCtx.loadCheckpoint(),
    { version: 1, phases: ["seeds", "local", "external", "critic", "final"] },
  );
  const resumeFrom = saved?.state;

  const config: AgenticWorkflowConfig<
    RelevantChunk,
    SearchTarget[],
    SearchTarget,
    ScrapedArtifact,
    ResearchReport
  > = {
    name: "deep_research",
    query,
    budgets: RESEARCH_BUDGETS,
    signal: runCtx.leaseSignal,
    resumeFrom,
    onProgress: runCtx.emitProgress,
    onCheckpoint: (snapshot) => {
      runCtx.saveCheckpoint(
        checkpoint({
          phase: snapshot.completedStages.at(-1) ?? "seeds",
          state: snapshot,
          roundsDone: snapshot.externalRounds,
        }),
      );
    },

    // 1. Page through existing local vector chunks first
    localKnowledge: {
      fetchBatch: (offset, limit) =>
        fetchRelevantChunks(queryVector, limit, offset, 0.42, userId),
      getId: (chunk) => chunk.id,
      getScore: (chunk) => chunk.similarity,
      formatEvidence: (chunk) =>
        `[Local: ${chunk.title ?? `doc#${chunk.documentId}`}]\n${chunk.chunkText}`,
    },

    // 2. Discover external URLs for unanswered intents
    externalDiscovery: {
      discover: (intent, ctx) => searchWeb(intent, ctx.signal),
      extractCandidates: (_intent, payload) => payload,
    },

    // 3. Extract markdown, chunk/embed, filter duplicates, and append high-signal evidence
    targetExecutor: {
      getKey: (target) => target.url,
      executeBatch: async (targets, state, ctx) => {
        const urls = targets.map((t) => t.url);
        const currentRound = Math.max(1, state.externalRounds);
        const extracted = (await extract(
          { urls },
          {
            toolCallId: `batch-${currentRound}`,
            signal: ctx.signal,
            callIndex: currentRound,
            callTotal: RESEARCH_BUDGETS.maxExternalRounds,
          },
        )) as { results?: { url: string; markdown?: string }[] };

        const byUrl = new Map(
          (extracted.results ?? []).map((item) => [
            item.url,
            item.markdown ?? "",
          ]),
        );

        let batchAdded = false;

        for (const target of targets) {
          if (ctx.signal?.aborted) break;

          const markdown = byUrl.get(target.url)?.trim();
          if (!markdown) {
            ctx.emit({ label: target.title, addedEvidence: false });
            continue;
          }

          const prepared = await prepareScrape(
            target.title,
            markdown,
            { url: target.url },
            { maxTokens: 900, overlapTokens: 100, embeddingConcurrency: 6 },
          );

          const filtered = await filterAdaptiveChunks(
            queryVector,
            prepared.chunks,
            accumulatedMatchingVectors,
            {
              candidateLimit: 6,
              minCoverage: 0.45,
              duplicateThreshold: 0.88,
              embeddingConcurrency: 6,
            },
          );

          if (filtered.acceptedChunks.length > 0) {
            accumulatedMatchingVectors.push(...filtered.newMatchingVectors);
            const snippet = filtered.acceptedChunks
              .map((c) => c.chunkText)
              .join("\n\n");
            state.appendEvidence(
              `[Web: ${target.title} (${target.url})]\n${snippet}`,
            );
            state.externalArtifacts.push({
              url: target.url,
              title: target.title,
              acceptedChunks: filtered.acceptedChunks.length,
            });
            batchAdded = true;
          }

          ctx.emit({
            label: target.title,
            addedEvidence: filtered.acceptedChunks.length > 0,
            custom: {
              url: target.url,
              acceptedChunks: filtered.acceptedChunks.length,
            },
          });
        }

        return batchAdded;
      },
    },

    // 4. Judge whether collected evidence is sufficient or propose new search intents
    evaluator: {
      evaluate: (input, ctx) =>
        runStructuredStage({
          stageName: "research_evaluator",
          model: MODEL,
          schema: EvaluatorVerdictSchema,
          signal: ctx.signal,
          messages: [
            {
              role: "system",
              content:
                "You are a strict research evaluator. Return JSON { isSufficient: boolean, nextIntents: string[] }. " +
                "Never repeat intents listed in issuedOrExhaustedIntents.",
            },
            {
              role: "user",
              content: JSON.stringify({
                query: input.query,
                phase: input.phaseDescription,
                coldStart: input.coldStart,
                issuedOrExhaustedIntents: input.issuedOrExhaustedIntents,
                evidence: input.evidenceText,
              }),
            },
          ],
        }),
    },

    // 5. Optional critic pass to catch missing angles before final report synthesis
    critic: {
      review: (state, ctx) =>
        runStructuredStage({
          stageName: "research_critic",
          model: MODEL,
          schema: CriticVerdictSchema,
          signal: ctx.signal,
          messages: [
            {
              role: "system",
              content:
                "Review the collected research evidence for gaps or unsupported claims. " +
                "Return JSON { approved: boolean, notes?: string, followUpIntents?: string[] }.",
            },
            {
              role: "user",
              content: JSON.stringify({
                query,
                evidenceCount: state.evidenceSet.length,
                evidence: state.evidenceSet.join("\n\n---\n\n"),
              }),
            },
          ],
        }),
    },

    // 6. Synthesize a typed citation-backed report
    finalAnswer: {
      synthesize: (result, ctx) =>
        runStructuredStage({
          stageName: "research_final_report",
          model: MODEL,
          schema: ResearchReportSchema,
          signal: ctx.signal,
          messages: [
            {
              role: "system",
              content:
                "Write an evidence-grounded research report as JSON matching the schema. " +
                "Cite every claim to an explicit source title or URL from the evidence.",
            },
            {
              role: "user",
              content: JSON.stringify({
                query,
                isSufficient: result.isSufficient,
                criticNotes: result.criticNotes,
                missingIntents: result.missingIntents,
                evidence: result.context,
              }),
            },
          ],
        }),
    },
  };

  const loop = new AgenticWorkflowLoop(config);
  const result = await loop.run();

  if (!result.report) {
    throw new Error(
      "Research workflow finished without synthesizing a report.",
    );
  }

  return {
    data: result.report,
    stopReason: result.stopReason,
    source: result.source,
    isSufficient: result.isSufficient,
    missingIntents: result.missingIntents,
    meta: {
      urls: result.externalArtifacts.map((a) => a.url),
    },
  };
}
```

## Expose as a resumable streaming HTTP endpoint

Combine `workflowStreamWithRegistry()`, `runProgressFrames()`, and `runWorkflow()` so clients stream live stage updates and can reattach or cancel mid-run. Register the matching `RunResumer` at server boot as shown in [Registering a Workflow Runner](/runs/registering-a-workflow-runner).

```ts [server/api/research.post.ts]
import {
  getConfiguration,
  runProgressFrames,
  runWorkflow,
  setSseHeaders,
  workflowStreamWithRegistry,
} from "@riavzon/ai";
import { executeResearchWorkflow } from "../../src/workflows/runResearchWorkflow";

export async function POST(req: Request, userId?: string): Promise<Response> {
  const { query } = (await req.json()) as { query: string };
  const runId = crypto.randomUUID();
  const log = getConfiguration().logger;

  const stream = workflowStreamWithRegistry({
    runId,
    kind: "workflow",
    log,
    execute: async ({ emit, signal }) => {
      const progress = runProgressFrames(emit, {
        query,
        workflow: "deep_research",
      });

      const payload = await runWorkflow(
        {
          kind: "workflow",
          name: "deep_research",
          query,
          userId,
          runId,
          signal,
          onRunStarted: progress.onRunStarted,
          onProgress: progress.onProgress,
        },
        (runCtx) => executeResearchWorkflow(query, runCtx, userId),
        log,
      );

      return { type: "research_result", payload };
    },
    onError: (err) => log.error({ err, runId }, "Research workflow failed"),
  });

  return new Response(stream, {
    headers: {
      ...setSseHeaders(),
      "X-Run-Id": runId,
    },
  });
}
```
