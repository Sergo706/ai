Every orchestration step that `createAgent()` performs internally is exported as an independent function. If you already have your own prompt assembly, routing conventions, or multi-model dispatch logic, you can assemble a complete streaming chat turn from these primitives directly.

## End-to-end custom streaming pipeline

The example below builds a complete custom chat route using `parseFiles()`, `resolveConversation()`, `tryCachedReply()`, `compactHistory()`, `executeToolLoop()`, `createEventSink()`, `TraceCollector`, `createRequestAbort()`, and `runAgentStream()` — without calling `createAgent()`.

```ts [src/custom-chat-route.ts]
import {
  aiClients,
  buildToolRegistry,
  compactHistory,
  createEventSink,
  createRequestAbort,
  EMPTY_COMPACTION_STATE,
  executeToolLoop,
  generateMatchingEmbedding,
  getConfiguration,
  makeCompactionHandler,
  parseFiles,
  resolveCommonTools,
  resolveConversation,
  runAgentStream,
  saveAssistantMessage,
  saveUserMessage,
  setSseHeaders,
  TraceCollector,
  tryCachedReply,
} from "@riavzon/ai";

export async function handleCustomChat(args: {
  userId: string;
  conversationId?: number;
  message: string;
  files?: File[];
  onDisconnect?: (cancel: () => void) => void;
}): Promise<Response> {
  const log = getConfiguration().logger;
  const client = aiClients();

  // 1. Extract attached files into Markdown text
  const { message, hasFiles } = await parseFiles(args.files, args.message);

  // 2. Load existing conversation + compaction watermark or create a new one
  const conv = await resolveConversation(
    args.userId,
    args.conversationId,
    args.message,
  );
  if (!conv.ok) {
    return new Response(conv.reason, { status: 404 });
  }

  // 3. Embed message and check semantic cache when no files were attached
  const embedding = await generateMatchingEmbedding(message);
  if (!hasFiles) {
    const hit = await tryCachedReply(["get_current_datetime"], {
      convId: conv.id,
      userId: args.userId,
      message,
      embedding,
      log,
      stream: true,
      similarity: 0.92,
      cacheWindowHours: 24,
    });
    if (hit instanceof ReadableStream) {
      return new Response(hit, { headers: setSseHeaders() });
    }
  }

  await saveUserMessage(conv.id, message, embedding);

  // 4. Compact older turns if history exceeds the token threshold
  const saveCompaction = makeCompactionHandler(conv.id);
  const compacted = await compactHistory(
    conv.history,
    conv.compaction ?? EMPTY_COMPACTION_STATE,
    {
      temperature: 0.2,
      maxTokens: 1024,
      tokenThreshold: 12_000,
      keepRecentMessages: 20,
      reserveTokens: 2048,
    },
    async (prompt) => {
      const res = await client.chat.completions.create({
        model: "gpt-4o-mini",
        temperature: 0.2,
        max_tokens: 1024,
        messages: [{ role: "user", content: prompt }],
      });
      return res.choices[0]?.message?.content ?? "";
    },
  );
  if (compacted.update.changed) {
    await saveCompaction(compacted.update);
  }

  // 5. Prepare tools, event sink, trace collector, and abort tracker
  const registry = buildToolRegistry(
    { userId: args.userId, conversationId: conv.id },
    resolveCommonTools(["calculator", "get_current_datetime"]),
  );
  const sink = createEventSink();
  const trace = new TraceCollector();
  const abort = createRequestAbort({
    meta: { convId: conv.id, userId: args.userId },
    onDisconnect: args.onDisconnect,
  });

  const agentIterable = executeToolLoop({
    client,
    model: "gpt-4o-mini",
    stream: true,
    signal: abort.signal,
    messages: [
      { role: "system", content: "You are a helpful assistant." },
      ...compacted.messages,
      { role: "user", content: message },
    ],
    availableTools: Object.values(registry.definitions),
    handlers: registry.handlers,
    tools: { temperature: 0.1, maxTokens: 2048, maxRounds: 5 },
    chat: { temperature: 0.4, maxTokens: 4096 },
    toolConcurrency: registry.toolConcurrency,
    toolStreaming: registry.toolStreaming,
    emit: (event) => sink.push(event),
    onToolResult: (step) => trace.addToolStep(step),
  });

  // 6. Stream events as SSE and persist the completed reply
  const body = runAgentStream({
    agent: agentIterable,
    convId: conv.id,
    sink,
    trace,
    abort,
    heartbeatMs: 10_000,
    onFinish: async () => {
      if (trace.fullResponse) {
        await saveAssistantMessage({
          conversationId: conv.id,
          content: trace.fullResponse,
          toolsUsed: [...registry.usedTools],
          trace: trace.toTrace(),
        });
      }
    },
  });

  return new Response(body, { headers: setSseHeaders() });
}
```

## Buffering out-of-band events with `createEventSink()`

Sometimes a tool or pre-loop step needs to emit `AgentEvent` frames before the `ReadableStream` consumer has attached. `createEventSink()` solves this race condition cleanly:

- `sink.push(event)`: queues events when detached, or forwards them immediately once attached.
- `sink.attach(consumer)`: flushes every queued event in order to `consumer` and delivers future pushes directly.
- `sink.detach()`: disconnects the consumer and clears any remaining queue.

```ts [src/event-sink.ts]
import { createEventSink } from "@riavzon/ai";

const sink = createEventSink();

// Emitted before HTTP stream starts — safely buffered
sink.push({ type: "agent_progress", agent: "planner", state: "running" });

// Later, when the SSE controller starts, buffered events replay in order
sink.attach((event) => {
  console.log("deliver:", event.type);
});

sink.detach();
```

## What `runAgentStream()` handles for you

`runAgentStream(params)` eliminates the fragile boilerplate of SSE stream controllers:

1. Emits `{ type: "init", conversationId }` immediately on stream start.
2. Attaches `sink` so buffered and live events route through `trace.apply(event)` and into `frame(event)`.
3. Sends `SSE_HEARTBEAT` (`: heartbeat\n\n`) on `heartbeatMs` (default `10000` ms) to keep reverse proxies and CDNs open.
4. Suppresses spurious error frames when the stream ends due to `RequestAbortedError` or `abort.signal.aborted`, while converting unexpected failures into a user-safe `{ type: "error", message }` frame.
5. Cleans up the heartbeat timer, detaches `sink`, calls `abort.markFinished()`, closes the stream controller, and awaits `onFinish()` in `finally` — even if the client disconnected mid-stream.
