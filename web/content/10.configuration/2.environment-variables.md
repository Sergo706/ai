Configure operational parameters in `@riavzon/ai` in code via `configuration()` and override them per environment (staging, production, CI) using integer environment variables. Invalid or below-minimum values clamp or fall back safely to their defaults.

## Run System leases & registry

| Variable                     | Default                                            | Min / Clamping                                   | Description                                                                                             |
| ---------------------------- | -------------------------------------------------- | ------------------------------------------------ | ------------------------------------------------------------------------------------------------------- |
| `RUNS_LEASE_TTL_MS`          | `config.runs.leaseTtlMs` (`60000`)                 | Min `5000`                                       | Milliseconds a run lease stays valid without a heartbeat before another replica treats it as abandoned. |
| `RUNS_HEARTBEAT_INTERVAL_MS` | `config.runs.heartbeatIntervalMs` (`15000`)        | Min `1000`, capped at half of `leaseTtlMs`       | Interval in milliseconds between lease heartbeat writes and cross-replica abort checks.                 |
| `RUNS_RETAIN_FINISHED_MS`    | `config.runs.registry.retainFinishedMs` (`600000`) | Min `0`, capped at the Redis stream TTL          | Milliseconds a settled run handle stays in process memory for zero-hop `streamFromRun()` replay.        |

## Run System Redis event store

| Variable                   | Default                                        | Min    | Description                                                                                                             |
| -------------------------- | ---------------------------------------------- | ------ | ----------------------------------------------------------------------------------------------------------------------- |
| `RUNS_STREAM_MAX_LEN`      | `config.runs.eventStore.maxStreamLen` (`5000`) | `100`  | Maximum events kept per run in both the in-memory ring buffer and Redis Stream (`XADD MAXLEN ~`).                       |
| `RUNS_STREAM_TTL_SECONDS`  | `config.runs.eventStore.ttlSeconds` (`3600`)   | `60`   | Expiration TTL in seconds applied to each run's Redis Stream key.                                                       |
| `RUNS_STREAM_BLOCK_MS`     | `config.runs.eventStore.blockMs` (`15000`)     | `1000` | Blocking read duration in milliseconds per `XREAD BLOCK` iteration before `streamFromStore()` re-checks `isRunAlive()`. |
| `RUNS_STREAM_REPLAY_BATCH` | `config.runs.eventStore.replayBatch` (`500`)   | `1`    | Number of entries fetched per `XRANGE` page when replaying historical frames.                                           |

## Run System crash recovery

| Variable                   | Default                                                                                     | Min   | Description                                                                                                  |
| -------------------------- | ------------------------------------------------------------------------------------------- | ----- | ------------------------------------------------------------------------------------------------------------ |
| `RUNS_SWEEP_INTERVAL_MS`   | `config.runs.recovery.sweepIntervalMs` (`0` uses half of `leaseTtlMs`, min `1000` ms)       | `100` | Interval in milliseconds between recovery sweep ticks.                                                       |
| `RUNS_MAX_ADOPT_PER_SWEEP` | `config.runs.recovery.maxAdoptPerSweep` (`3`)                                               | `1`   | Maximum abandoned runs adopted in one sweep cycle (prevents thundering herds after a mass crash).            |
| `RUNS_MAX_RESUME_ATTEMPTS` | `config.runs.recovery.maxResumeAttempts` (`5`)                                              | `0`   | Maximum claim/resume attempts allowed per run across both automatic recovery and manual `retryRun()`.        |
| `RUNS_UNCLAIMED_GRACE_MS`  | `config.runs.recovery.unclaimedGraceMs` (`600000`)                                          | `0`   | Grace window in milliseconds before closing an abandoned run whose `(kind, name)` has no registered resumer. |

## Tools, files & document budgets

| Variable                       | Default            | Min    | Description                                                                                              |
| ------------------------------ | ------------------ | ------ | -------------------------------------------------------------------------------------------------------- |
| `AGENT_GENERATED_FILE_TTL`     | `86400` (24 hours) | `0`    | Cache TTL in seconds for PDFs and spreadsheets created by `pdf_creator` and `create_styled_spreadsheet`. |
| `EXTRACTOR_MAX_CONTENT_TOKENS` | `50000`            | `1000` | Maximum extracted text tokens returned by the built-in `extractor` tool.                                 |
| `EXTRACTOR_CACHE_TTL_SECONDS`  | `86400` (24 hours) | `0`    | Cache TTL in seconds for URL extractions cached by the `extractor` tool.                                 |
| `DOCUMENT_MAX_TOKENS`          | `3000`             | —      | Whole-document token ceiling applied by `readToolDocument()` / `get_document`.                           |
| `DOCUMENT_CHUNK_TOKENS`        | `1000`             | —      | Per-chunk token cap applied by `readToolDocument()` / `get_document`.                                    |

## Example `.env` file

```bash [.env]
# Core credentials (read by your application code and passed into configuration())
OPENAI_API_KEY=sk-...
DATABASE_URL=postgresql://user:pass@localhost:5432/ai_prod
REDIS_URL=redis://localhost:6379

# Optional @riavzon/ai runtime overrides
RUNS_LEASE_TTL_MS=45000
RUNS_HEARTBEAT_INTERVAL_MS=10000
RUNS_STREAM_TTL_SECONDS=7200
RUNS_MAX_RESUME_ATTEMPTS=5
AGENT_GENERATED_FILE_TTL=43200
EXTRACTOR_MAX_CONTENT_TOKENS=32000
DOCUMENT_MAX_TOKENS=4000
```
