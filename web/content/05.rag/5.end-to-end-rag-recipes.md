This page combines the `@riavzon/ai` RAG building blocks into two complete end-to-end pipelines:

1. **Ingest → Scoped Agent Chat**: upload Markdown/text documents via multipart HTTP form data, persist deduplicated embeddings per user, and answer user questions with tenant-isolated citations.
2. **Crawl → `prepareScrape` → `filterAdaptiveChunks` → Persist**: extract live web pages, chunk and embed them, discard off-topic and near-duplicate chunks across pages, and persist only the surviving chunks with their existing vectors.

## Recipe 1: Ingest → multi-tenant scoped agent chat

Use `saveUploadedScrappedFile()` in your upload route and pair it with an agent whose `search_db` and `get_document` tools are scoped to `ctx.userId`.

### 1. Create the tenant-scoped RAG agent

```ts [server/lib/docsAgent.ts]
import OpenAI from "openai";
import { Pool } from "pg";
import { configuration, createAgent, getDocument, searchDb } from "@riavzon/ai";

export const pool = new Pool({ connectionString: process.env.DATABASE_URL! });

await configuration({
  openAiConfig: new OpenAI({ apiKey: process.env.OPENAI_API_KEY! }),
  embeddingConfig: {
    retrievalModel: "text-embedding-3-small",
    matchingModel: "text-embedding-3-small",
    dimensions: 1536,
  },
  db: pool,
  redis: "memory",
});

export const docsAgent = await createAgent({
  model: {
    model: "gpt-4o-mini",
    temperature: 0.2,
    tools: { maxRounds: 5, maxCalls: 12 },
  },
  systemInstructions: [
    "Answer questions strictly from the user's uploaded knowledge base.",
    "Start with search_db to find relevant chunks.",
    "If a chunk cuts off mid-section, call get_document with its documentId to read surrounding chunks.",
    "Cite every claim inline using [Title (doc #<documentId>)]. If no matching documents exist, say so.",
  ].join("\n"),
  tools: {
    common: [
      {
        name: "search_db",
        // Scope BOTH the SQL query and the cache key to the authenticated user
        cache: { ttl: 3600, scoped: true },
        make: (ctx) => searchDb(ctx.userId),
      },
      {
        name: "get_document",
        maxCalls: 6,
        make: (ctx) =>
          getDocument(ctx.userId, {
            maxDocTokens: 4000,
            maxChunksPerRead: 8,
          }),
      },
    ],
  },
  conversation: { persist: true },
});
```

### 2. Wire upload and streaming chat routes

```ts [server/api/ragRoutes.ts]
import {
  framesToStream,
  saveUploadedScrappedFile,
  setSseHeaders,
} from "@riavzon/ai";
import { docsAgent } from "../lib/docsAgent";

// POST /api/documents (multipart/form-data with one or more .md / .txt files)
export async function POST_upload(
  req: Request,
  userId: string,
): Promise<Response> {
  const formData = await req.formData();

  const summary = await saveUploadedScrappedFile(formData, userId, {
    extensions: [".md", ".txt"],
    batchSize: 100,
    prepare: {
      maxTokens: 800,
      overlapTokens: 100,
      embeddingConcurrency: 8,
    },
  });

  // Re-uploading identical content lands in `skippedDuplicates` instead of re-embedding
  return Response.json(summary, {
    status:
      summary.errors.length > 0 && summary.ingested.length === 0 ? 400 : 200,
  });
}

// POST /api/docs-chat
export async function POST_chat(
  req: Request,
  userId: string,
): Promise<Response> {
  const { message, conversationId } = (await req.json()) as {
    message: string;
    conversationId?: number;
  };

  const turn = await docsAgent.chat({
    userId,
    conversationId,
    message,
    signal: req.signal,
  });

  return new Response(framesToStream(turn.frames), {
    headers: setSseHeaders(),
  });
}
```

::tip
Because `saveUploadedScrappedFile()` computes a SHA-256 content hash per uploaded file before calling `prepareScrape()`, accidental duplicate uploads skip embedding API calls automatically.
::

## Recipe 2: Crawl → `prepareScrape` → `filterAdaptiveChunks` → persist

When crawling external URLs for a research topic, pages often share boilerplate navigation, repeated FAQs, or off-topic paragraphs. Instead of storing every raw chunk, run each crawled page through `prepareScrape()` and `filterAdaptiveChunks()` while accumulating `newMatchingVectors` across pages so later pages deduplicate against earlier ones too.

```ts [src/rag/crawlAndPersist.ts]
import { createHash } from "node:crypto";
import { Kysely, PostgresDialect } from "kysely";
import {
  extractor,
  filterAdaptiveChunks,
  generateEmbedding,
  prepareScrape,
  toVec,
  type Database,
} from "@riavzon/ai";
import { pool } from "../../server/lib/docsAgent";

const db = new Kysely<Database>({
  dialect: new PostgresDialect({ pool }),
});

interface CrawlChunkMeta {
  url: string;
  chunkIndex: number;
}

interface ExtractedItem {
  url: string;
  markdown?: string;
  error?: string;
}

export async function crawlFilterAndPersist(
  topic: string,
  urls: string[],
  userId: string,
) {
  // 1. Embed the target topic once in retrieval space (matches prepareScrape chunk embeddings)
  const queryVector = await generateEmbedding(topic);

  // 2. Crawl pages with limitDataTokens = false so full sanitized markdown is returned
  const extract = extractor(false);
  const extracted = (await extract(
    { urls },
    { toolCallId: "crawl-job", callIndex: 1, callTotal: 1 },
  )) as { results?: ExtractedItem[] };

  const pages = (extracted.results ?? []).filter(
    (item): item is { url: string; markdown: string } =>
      typeof item.markdown === "string" && item.markdown.trim().length > 0,
  );

  // Accumulate matching-space vectors across every crawled URL for cross-page dedupe
  const accumulatedMatchingVectors: number[][] = [];
  const persistedDocIds: number[] = [];

  for (const page of pages) {
    // 3. Token-aware chunking + retrieval embeddings with per-chunk metadata
    const prepared = await prepareScrape<{ url: string }, CrawlChunkMeta>(
      page.url,
      page.markdown,
      { url: page.url },
      {
        maxTokens: 900,
        overlapTokens: 100,
        embeddingConcurrency: 8,
        chunkMeta: (_text, index) => ({ url: page.url, chunkIndex: index }),
      },
    );

    // 4. Keep only high-coverage, non-duplicate chunks
    const filtered = await filterAdaptiveChunks<CrawlChunkMeta>(
      queryVector,
      prepared.chunks,
      accumulatedMatchingVectors,
      {
        candidateLimit: 12,
        minCoverage: 0.45,
        duplicateThreshold: 0.88,
        embeddingConcurrency: 6,
      },
    );

    if (filtered.acceptedChunks.length === 0) continue;

    // Carry accepted matching vectors forward so subsequent URLs drop overlapping claims
    accumulatedMatchingVectors.push(...filtered.newMatchingVectors);

    // 5. Persist document + surviving chunks in one transaction without re-embedding
    const contentHash = createHash("sha256")
      .update(prepared.fullContent)
      .digest("hex");

    const existing = await db
      .selectFrom("documents")
      .select("id")
      .where("content_hash", "=", contentHash)
      .limit(1)
      .executeTakeFirst();
    if (existing) continue;

    const docId = await db.transaction().execute(async (tx) => {
      const inserted = await tx
        .insertInto("documents")
        .values({
          title: prepared.title,
          raw_content: prepared.fullContent,
          content_hash: contentHash,
          user_id: userId,
        })
        .returning("id")
        .executeTakeFirstOrThrow();

      await tx
        .insertInto("document_chunks")
        .values(
          filtered.acceptedChunks.map((chunk, idx) => ({
            document_id: inserted.id,
            chunk_index: idx,
            chunk_text: chunk.chunkText,
            embedding: toVec(chunk.embedding),
          })),
        )
        .execute();

      return inserted.id;
    });

    persistedDocIds.push(docId);
  }

  return {
    crawledPages: pages.length,
    persistedDocIds,
    totalAcceptedChunks: accumulatedMatchingVectors.length,
  };
}
```

::note
If you do not need adaptive coverage or cross-page deduplication and simply want to ingest full Markdown strings straight into `documents` and `document_chunks`, pass an in-memory array directly to `saveUploadedScrappedFile([{ name: "page.md", data: markdown }], userId)` instead of writing a manual Kysely transaction.
::
