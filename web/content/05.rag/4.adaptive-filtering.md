When agents crawl live web pages or ingest external research documents, raw scrapes often contain redundant paragraphs, boilerplate sections, or facts already stored in your knowledge base. `filterAdaptiveChunks()` narrows freshly prepared chunks down to only high-coverage, non-duplicate evidence — and computes matching embeddings only for chunks that survive relevance filtering.

## How adaptive filtering works

`filterAdaptiveChunks(queryVector, existingMatchingVectors, incomingChunks, config)` runs in three phases:

1. **Relevance scoring**: Computes cosine similarity (`calculateCosineSimilarity()`) between `queryVector` and each incoming chunk's `embedding`. Drops chunks scoring below `config.minCoverage`.
2. **Candidate selection**: Sorts surviving chunks by `coverageScore` descending and keeps the top `config.candidateLimit` candidates.
3. **Deduplication**: Embeds surviving candidates with `generateMatchingEmbedding()` (bounded by `config.embeddingConcurrency`) and compares each candidate against `existingMatchingVectors` plus vectors already accepted in the current batch. Chunks with similarity ≥ `config.duplicateThreshold` are dropped unless `config.byPassAuthorityDedupe?.(chunk)` returns `true`.

```ts [src/adaptive-filter.ts]
import {
  filterAdaptiveChunks,
  generateEmbedding,
  prepareScrape,
  type AdaptiveFilterConfig,
} from "@riavzon/ai";

interface SourceMeta {
  url: string;
  isOfficialDoc: boolean;
}

// 1. Prepare scraped content with typed per-chunk metadata
const prepared = await prepareScrape<SourceMeta, SourceMeta>(
  "Official API Spec",
  scrapedMarkdown,
  { url: "https://docs.vendor.com/api", isOfficialDoc: true },
  {
    maxTokens: 600,
    overlapTokens: 80,
    chunkMeta: (_index, _total, data) => data,
  },
);

// 2. Embed the research query with the retrieval model (same vector space as prepared.chunks)
const queryVector = await generateEmbedding(
  "How does OAuth token refresh handle rotation?",
);

// 3. Filter and deduplicate against already-collected matching vectors
const config: AdaptiveFilterConfig<SourceMeta> = {
  candidateLimit: 12,
  minCoverage: 0.45,
  duplicateThreshold: 0.9,
  embeddingConcurrency: 8,
  // Optional: allow authoritative sources to override duplicate rejection
  byPassAuthorityDedupe: (chunk) => chunk.meta?.isOfficialDoc === true,
};

const result = await filterAdaptiveChunks(
  queryVector,
  existingMatchingVectors,
  prepared.chunks,
  config,
);

console.log({
  kept: result.acceptedChunks.length,
  keptByAuthority: result.acceptedByAuthority,
  droppedDuplicates: result.rejectedAsDuplicate,
});

// Carry newly accepted matching vectors forward into the next scrape round
existingMatchingVectors.push(...result.newMatchingVectors);
```

## Configuration options (`AdaptiveFilterConfig<C>`)

::field-group
  :::field{name="candidateLimit" type="number" required}
  Maximum number of relevance-filtered chunks to send through matching-embedding deduplication.
  :::

  :::field{name="minCoverage" type="number" required}
  Minimum cosine similarity (`0` to `1`) between `queryVector` and `chunk.embedding` required for a chunk to be considered relevant.
  :::

  :::field{name="duplicateThreshold" type="number" required}
  Cosine similarity threshold (`0` to `1`) above which a candidate chunk is considered a near-duplicate of an existing vector or an earlier accepted chunk in the same batch.
  :::

  :::field{name="embeddingConcurrency" type="number" required}
  Concurrency limit for `generateMatchingEmbedding()` calls on surviving candidates.
  :::

  :::field{name="byPassAuthorityDedupe" type="(chunk: PreparedChunk<C>) => boolean"}
  Optional escape hatch. When it returns `true`, a chunk is accepted even if its similarity exceeds `duplicateThreshold`, incrementing `result.acceptedByAuthority`.
  :::
::

## Return value (`AdaptiveFilterResult<C>`)

| Field | Type | Description |
| --- | --- | --- |
| `acceptedChunks` | `AcceptedAdaptiveChunk<C>[]` | Surviving chunks sorted by `coverageScore` descending (each extends `PreparedChunk<C>` with `coverageScore: number`). |
| `newMatchingVectors` | `number[][]` | Matching vectors for each accepted chunk — append these to your running vector list before the next filtering round. |
| `acceptedByAuthority` | `number` | Count of chunks admitted solely because `byPassAuthorityDedupe()` returned `true`. |
| `rejectedAsDuplicate` | `number` | Count of candidates dropped for exceeding `duplicateThreshold`. |

::tip
Because `filterAdaptiveChunks()` embeds candidates with `generateMatchingEmbedding()` *only after* `minCoverage` and `candidateLimit` drop irrelevant chunks, you avoid paying embedding costs for noisy navigation menus, footers, or off-topic paragraphs.
::
