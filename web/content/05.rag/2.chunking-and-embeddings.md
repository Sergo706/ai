Before documents enter your vector store, `@riavzon/ai` splits them into overlapping token-bounded chunks and generates validated dense vectors in parallel batches.

## Generate embeddings

Use `generateEmbedding()` for stored document chunks and `generateMatchingEmbedding()` for search queries, semantic cache lookups, and deduplication checks.

```ts [src/embeddings.ts]
import { generateEmbedding, generateMatchingEmbedding } from "@riavzon/ai";

// Uses embeddingConfig.retrievalModel (falls back to aiClient if embeddingClient is unset)
const docVector: number[] = await generateEmbedding(
  "Kysely supports type-safe PostgreSQL and SQLite queries.",
);

// Uses embeddingConfig.matchingModel
const queryVector: number[] = await generateMatchingEmbedding(
  "Which databases does Kysely support?",
);
```

Both functions inspect `embedding.length` against `getConfiguration().embeddingConfig.dimensions` and throw if the model returns a different vector width.

## Token-aware chunking (`chunkByTokens`)

`chunkByTokens(text, maxTokens?, overlapTokens?, tokenizer?, charsPerTokenEstimate?)` splits long text along paragraph and line boundaries while honoring token limits and configurable overlap between adjacent chunks.

```ts [src/chunking.ts]
import { chunkByTokens, countTokens } from "@riavzon/ai";

const rawText = "...long markdown document...";
const totalTokens = countTokens(rawText);

const chunks: string[] = chunkByTokens(
  rawText,
  1000,      // maxTokens per chunk (default: 1000)
  100,       // overlapTokens carried into the next chunk (default: 100)
  undefined, // optional Hugging Face PreTrainedTokenizer
  4,         // charsPerTokenEstimate used when tokenizer is omitted (default: 4)
);
```

When `tokenizer` is omitted, `countTokens()` and `chunkByTokens()` use the fast character heuristic (`Math.ceil(text.length / charsPerTokenEstimate)`). Pass a `PreTrainedTokenizer` from `@huggingface/transformers` for exact model-specific token counts.

## Prepare documents with `prepareScrape()`

`prepareScrape<T, C>(title, rawMarkdown, jsonData, options?)` combines optional Markdown formatting, token chunking, metadata tagging, and concurrent batch embedding into one step.

```ts [src/prepare-doc.ts]
import { prepareScrape } from "@riavzon/ai";

interface PageMeta {
  url: string;
  section: string;
}

interface ChunkMeta {
  url: string;
  part: number;
}

const prepared = await prepareScrape<PageMeta, ChunkMeta>(
  "Billing Guide",
  rawMarkdown,
  { url: "https://docs.example.com/billing", section: "payments" },
  {
    maxTokens: 800,
    overlapTokens: 100,
    embeddingConcurrency: 10,
    // Optional: enrich or normalize the raw Markdown using title and structured jsonData
    formatter: (title, markdown, data) =>
      `# ${title}\nSource: ${data.url}\n\n${markdown}`,
    // Optional: attach typed customFields to every chunk (e.g., for adaptive filtering)
    chunkMeta: (_chunkText, chunkIndex) => ({
      url: "https://docs.example.com/billing",
      part: chunkIndex + 1,
    }),
  },
);

console.log(prepared.title);           // "Billing Guide"
console.log(prepared.fullContent);     // Formatted Markdown ready for documents.raw_content
console.log(prepared.chunks.length);   // Number of embedded chunks
console.log(prepared.chunks[0]);       // { chunkIndex: 0, chunkText: "...", embedding: number[], customFields?: ChunkMeta }
```

### `PrepareScrapeOptions<T, C>`

::field-group
  :::field{name="maxTokens" type="number" default="1000"}
  Maximum token budget per chunk.
  :::

  :::field{name="overlapTokens" type="number" default="100"}
  Number of overlapping tokens repeated across consecutive chunks so split sentences retain context.
  :::

  :::field{name="tokenizer" type="PreTrainedTokenizer"}
  Optional `@huggingface/transformers` tokenizer. When omitted, token length is estimated from `charsPerTokenEstimate`.
  :::

  :::field{name="charsPerTokenEstimate" type="number" default="4"}
  Fallback character-to-token ratio used when `tokenizer` is not provided.
  :::

  :::field{name="embeddingConcurrency" type="number" default="10"}
  Maximum number of concurrent `generateEmbedding()` calls executed in parallel.
  :::

  :::field{name="formatter" type="(title: string, rawText: string, jsonData: T) => string"}
  Optional transformation applied before chunking. Defaults to `rawMarkdown`.
  :::

  :::field{name="chunkMeta" type="(chunkText: string, chunkIndex: number) => C"}
  Optional callback attaching custom typed `customFields: C` to each `PreparedChunk<C>`.
  :::
::

::tip
When you only need embeddings and chunks without touching the SQL database (for example, feeding an external vector store like Qdrant or Pinecone, or passing chunks into `filterAdaptiveChunks()`), call `prepareScrape()` directly.
::
