These pure, dependency-light utilities handle the messy edges of working with real-world LLM outputs: broken JSON, `<think>` tags, code fences, token budgets, nested API payloads, and duplicate search queries.

## Structured JSON repair (`llmSchemaParser`)

`llmSchemaParser(schema, llmResponse, configs, logger?)` validates a `ChatCompletion` against a Zod schema. It strips thinking blocks and code fences, parses JSON, validates with `schema.safeParse()`, and — if parsing or validation fails — invokes your `configs.retry(request)` callback up to `maxRetries` times with the exact Zod errors and rendered JSON Schema.

```ts [src/parse-extraction.ts]
import { z } from "zod";
import { aiClients, llmSchemaParser } from "@riavzon/ai";

const InvoiceSchema = z.object({
  vendor: z.string(),
  totalUsd: z.number().nonnegative(),
  lineItems: z.array(
    z.object({
      description: z.string(),
      amount: z.number(),
    }),
  ),
});

const client = aiClients();
const messages = [
  { role: "system" as const, content: "Extract invoice data as JSON." },
  { role: "user" as const, content: rawInvoiceText },
];

const initial = await client.chat.completions.create({
  model: "gpt-4o-mini",
  messages,
});

const invoice = await llmSchemaParser(InvoiceSchema, initial, {
  agent: "invoice-extractor",
  messages,
  schemaName: "invoice",
  maxRetries: 2,              // Default: 2 repair attempts after initial completion
  includeSchemaInPrompt: true, // Default: true
  retry: (request) =>
    client.chat.completions.create({
      model: "gpt-4o-mini",
      temperature: 0,
      ...request, // Contains updated messages + strict response_format when supported
    }),
});

// Fully typed as z.output<typeof InvoiceSchema>
console.log(invoice.vendor, invoice.totalUsd);
```

::note
`llmSchemaParser()` throws immediately if the completion was empty, refused, or truncated (`finish_reason !== "stop"`), or if all repair attempts fail. Requires `openai` (already installed as a peer dependency).
::

## Stripping thinking tags & code fences

Reasoning models frequently wrap chain-of-thought text in `<think>...</think>` tags or wrap JSON payloads in `` ```json `` blocks. Clean them cleanly before parsing:

```ts [src/clean-output.ts]
import { removeCodeFence, removeThinking } from "@riavzon/ai";

const raw = '<think>Checking totals...</think>\n```json\n{"ok":true}\n```';
const clean = removeCodeFence(removeThinking(raw));
// '{"ok":true}'
```

## Token counting & message estimation

Choose between exact local tokenization (`countTokens`) and fast zero-allocation heuristics (`estimateMessageTokens`, `estimateMessagesTokens`, `estimateTextTokens`) when checking context-window budgets:

```ts [src/token-budget.ts]
import {
  chunkByTokens,
  countTokens,
  estimateMessagesTokens,
  estimateMessageTokens,
  estimateTextTokens,
} from "@riavzon/ai";

// Token count using an optional Hugging Face PreTrainedTokenizer (falls back to 4 chars/token)
const tokens = countTokens("Hello, world!");

// Fast character heuristic (rounds up: Math.ceil(text.length / charsPerToken))
const approxTokens = estimateTextTokens("Hello, world!", 4);

// Estimate chat message lists including tool calls, non-text parts (85 tokens), and overhead (4 tokens)
const totalHistoryTokens = estimateMessagesTokens(
  messages,
  4,   // MESSAGE_OVERHEAD_TOKENS (default: 4)
  3.6, // CHARS_PER_TOKEN (default: 3.6)
  85,  // NON_TEXT_PART_TOKENS (default: 85)
);

const singleCost = estimateMessageTokens(messages[0]);
```

## Rendering JSON for LLM prompts (`jsonToMarkdown`)

LLMs read structured Markdown more reliably and with fewer tokens than deeply nested escaped JSON. `jsonToMarkdown(value, options?)` recursively renders arbitrary objects and arrays into headed sections and bullet lists while safely handling circular references.

```ts [src/render-payload.ts]
import { jsonToMarkdown } from "@riavzon/ai";

const md = jsonToMarkdown(
  {
    symbol: "AAPL",
    price: 218.5,
    metrics: { peRatio: 32.1, marketCap: "3.3T" },
    news: [{ headline: "Quarterly earnings beat expectations", sentiment: "positive" }],
  },
  {
    headingLevel: 2,          // Default: 2
    maxDepth: 4,              // Default: Infinity (deeper values flatten onto one line)
    maxArrayItems: 10,        // Default: Infinity (excess items summarized)
    maxStringLength: 500,     // Default: Infinity
    maxTotalLength: 12_000,   // Default: Infinity
    omitEmpty: true,          // Default: false (when false, empty values render as "_(none)_")
    titleKeys: ["headline", "symbol", "title", "name"],
  },
);
```

## Query fingerprinting & URL safety

```ts [src/query-and-url.ts]
import { fingerprintQuery, isHttpUrl, safeUrlProtocol } from "@riavzon/ai";

// Lowercases, drops 19xx/20xx years, punctuation, and stop words, then sorts tokens
fingerprintQuery("Best Laptops for Developers in 2025?");
// => "best developers laptops"

// Safe protocol inspection (never throws on malformed URLs)
safeUrlProtocol("https://example.com/docs"); // "https:"
safeUrlProtocol("not a url");                // ""

// Strict http:/https: check (rejects javascript:, data:, file:, relative paths)
isHttpUrl("https://example.com/docs"); // true
isHttpUrl("javascript:alert(1)");      // false
```
