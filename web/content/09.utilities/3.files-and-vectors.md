`@riavzon/ai` includes standalone document and spreadsheet utilities (the exact same engines powering attachment parsing, `pdf_creator`, and `create_styled_spreadsheet`) plus vector similarity math. Heavy binary libraries (`pdf-lib`, `@pdf-lib/fontkit`, `exceljs`) are loaded dynamically only when you invoke them.

## Read & create PDFs

### Extract text to Markdown (`readPdf`)

`readPdf({ fileBuffer, maxPages?, includeMetadata? })` parses PDF bytes into a Markdown document with an optional metadata header and `--- Page N ---` markers (`maxPages: 0` reads every page).

```ts [src/read-pdf.ts]
import { readFile } from "node:fs/promises";
import { readPdf } from "@riavzon/ai";

const markdown = await readPdf({
  fileBuffer: await readFile("./contract.pdf"),
  maxPages: 5,           // Default: 0 (all pages)
  includeMetadata: true, // Default: true
});
```

### Build or annotate PDFs (`createPdf`)

`createPdf(params)` creates a fresh PDF or draws onto an existing `basePdfBase64` document, embedding bundled Unicode `DejaVu` / `DejaVuBold` fonts as well as standard PDF fonts (`Helvetica`, `HelveticaBold`, `TimesRoman`, `Courier`). Requires optional peers `pdf-lib` and `@pdf-lib/fontkit`.

```ts [src/create-pdf.ts]
import { createPdf } from "@riavzon/ai";

const pdf = await createPdf({
  filename: "summary.pdf",
  metadata: {
    title: "Monthly Summary",
    author: "Analytics Bot",
  },
  pages: [
    {
      action: "add",
      dimensions: [595, 842], // A4 points
      items: [
        { type: "text", x: 50, y: 780, text: "Monthly Summary", size: 20, font: "DejaVuBold" },
        { type: "text", x: 50, y: 740, text: "Revenue increased 18% MoM.", size: 12 },
      ],
    },
  ],
});

// Returns { buffer, base64Data, mimeType: "application/pdf", filename }
```

## Read & generate spreadsheets

All spreadsheet helpers dynamically import the optional `exceljs` peer dependency.

```ts [src/spreadsheets.ts]
import { readFile } from "node:fs/promises";
import {
  generateStyledSpreadsheet,
  readCsvToMarkdown,
  readXlsxToMarkdown,
} from "@riavzon/ai";

// Convert XLSX or CSV buffers into LLM-friendly Markdown tables
const xlsxMd = await readXlsxToMarkdown(await readFile("./sales.xlsx"));
const csvMd = await readCsvToMarkdown(await readFile("./users.csv"));

// Create a styled Excel workbook (or CSV) from plain objects
const workbook = await generateStyledSpreadsheet(
  [
    { region: "US-East", revenue: 142_000, growth: "14%" },
    { region: "EU-West", revenue: 98_500, growth: "21%" },
  ],
  {
    filename: "quarterly-report.xlsx",
    sheetName: "Q3 Results",
    format: "xlsx", // "xlsx" | "csv"
  },
);
```

## Serve tool-generated files (`readGeneratedFile` & `fileKey`)

When the built-in `pdf_creator` or `create_styled_spreadsheet` tool runs, it stores the generated bytes in Redis under `fileKey(id)` (`file:<id>`) for `AGENT_GENERATED_FILE_TTL` seconds (default `86400` = 24 hours) and gives the model a download path pointing at your configured `downloadPath` (default `"/api/files"`).

Mount a single download endpoint calling `readGeneratedFile(id)` to serve those links safely with exact binary `Content-Length` and attachment headers:

```ts [src/routes/files.ts]
import { readGeneratedFile } from "@riavzon/ai";

export async function GET(
  _req: Request,
  { params }: { params: { id: string } },
): Promise<Response> {
  const result = await readGeneratedFile(params.id);

  if (!result.ok) {
    // result.reason is "not_found" (expired/missing) or "corrupt"
    const status = result.reason === "not_found" ? 404 : 500;
    return new Response(result.message, { status });
  }

  return new Response(new Uint8Array(result.file.buffer), {
    status: 200,
    headers: result.file.headers,
  });
}
```

## Vector math (`calculateCosineSimilarity`)

Compare two equal-length numeric embeddings directly in JavaScript (for example inside custom re-rankers, clustering routines, or local similarity gates):

```ts [src/vector-math.ts]
import { calculateCosineSimilarity } from "@riavzon/ai";

const score = calculateCosineSimilarity(vecA, vecB);
// Returns a value between -1 and 1 (0 if either vector has zero magnitude)
```
