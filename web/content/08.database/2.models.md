Every database operation used by `createAgent()`, the RAG pipeline, and the Run System is exported as a typed standalone function. Use them to build sidebar conversation lists, message history views, custom chat routes, document managers, and run-inspection dashboards.

## Conversations & messages

Build chat UIs and custom history loaders using these thread models:

```ts [src/routes/conversations.ts]
import {
  getConversations,
  getMessages,
  loadConversationHistory,
  saveAssistantMessage,
  saveCachedExchange,
  saveConversationCompaction,
  saveUserMessage,
} from "@riavzon/ai";

// 1. Paginated list of conversations for a sidebar (newest updated first)
const list = await getConversations("user_42", 50, 0);
// { ok: true, date: "...", data: [{ id, title, createdAt, updatedAt }, ...] }

// 2. Full message thread for a conversation (enforces userId ownership)
const thread = await getMessages("user_42", 101);
// { ok: true, data: [{ id, role, content, trace, toolsUsed, createdAt }, ...] }
// or { ok: false, reason: "Conversation not found" }

// 3. Load history + compaction watermark, or create a new conversation if conversationId is undefined
const loaded = await loadConversationHistory("user_42", undefined, "Hello!");
```

| Function | Signature | Description |
| --- | --- | --- |
| `getConversations` | `(userId, limit = 50, offset = 0)` | Lists a user's conversations sorted by `updated_at DESC`. |
| `getMessages` | `(userId, conversationId)` | Returns all messages in chronological order after verifying ownership. |
| `loadConversationHistory` | `(userId, conversationId \| undefined, currentMessage)` | Loads `{ existedId, conversation, compaction }` or creates a new conversation titled from `currentMessage`. |
| `saveUserMessage` | `(conversationId, content, embedding)` | Inserts a `"user"` message with its encoded vector embedding. |
| `saveAssistantMessage` | `({ conversationId, content, toolsUsed, trace })` | Inserts an `"assistant"` message with serialized `tools_used` and `MessageTrace`; returns `{ id }` or `null`. |
| `saveCachedExchange` | `(conversationId, userContent, embedding, assistantContent)` | Inserts both the user question and cached assistant reply in one batch statement. |
| `saveConversationCompaction` | `(conversationId, update)` | Updates `compacted_summary` and `compacted_through_message_id` when `update.changed` is `true`. |

## Semantic cache

`checkChatSemanticCache()` queries recent user messages by cosine similarity and excludes turns whose assistant response invoked any tool listed in `poisonTools`.

```ts [src/semantic-cache-check.ts]
import { checkChatSemanticCache, generateMatchingEmbedding } from "@riavzon/ai";

const queryVec = await generateMatchingEmbedding("What are your support hours?");

const hit = await checkChatSemanticCache(
  queryVec,
  0.92,                     // Minimum cosine similarity
  24,                       // Lookback window in hours (default: 24)
  ["get_current_datetime"], // Disqualify answers that called time-sensitive tools
  "user_42",                // Optional userId scope (recommended for multi-tenant apps)
);

if (hit.hit) {
  console.log("Matched message #", hit.matchedMessageId, hit.content);
}
```

::warning
In multi-tenant applications, always pass `userId` to `checkChatSemanticCache()` so one user's private answer is never served to another user.
::

## RAG & documents

| Function | Signature | Description |
| --- | --- | --- |
| `saveUploadedScrappedFile` | `(files, userId?, options?)` | Deduplicates by SHA-256 content hash, chunks, embeds, and batch-inserts uploaded files. |
| `fetchRelevantChunks` | `(queryVector, limit = 10, offset = 0, similarityThreshold = 0.1, userId?)` | Vector similarity search across `document_chunks` joined with `documents`. |
| `searchDbDocs` | `(conf: SearchDbParams, userId?)` | Embeds `conf.query` and delegates to `fetchRelevantChunks()`. Validate inputs with `searchParams`. |
| `readToolDocument` | `(userId, { documentId, chunkStart?, chunkEnd? }, charsPerToken?, maxDocTokens?, chunkTokenCap?, maxChunksPerRead?)` | Reads a user-scoped document or inclusive chunk range (max 10 chunks) truncated to token caps. |

## Runs, leases & checkpoints

Inspect run history, build resumable UI banners, or persist custom chat runs directly:

```ts [src/routes/conversation-runs.ts]
import {
  getLatestResumableRun,
  getRunById,
  getRunsByConversation,
  getUnpersistedRuns,
} from "@riavzon/ai";

// Show all runs associated with a conversation
const runs = await getRunsByConversation(101, 20);

// Offer a "Resume interrupted workflow" banner when a user reopens a chat
const resumable = await getLatestResumableRun({
  conversationId: 101,
  userId: "user_42",
  kind: "workflow",
});

// Find settled runs for a user (signature: getUnpersistedRuns(userId, limit = 20, kind = "workflow"))
const unpersisted = await getUnpersistedRuns("user_42", 20, "workflow");
```

| Category | Exports |
| --- | --- |
| **Run CRUD & queries** | `createRun`, `updateRun`, `getRunById`, `getRunsByConversation`, `getLatestResumableRun`, `getUnpersistedRuns`, `persistChatRun` |
| **Leases & ownership** | `INSTANCE_ID`, `claimRun`, `reopenRunForRetry`, `heartbeatRun`, `startLeaseHeartbeat`, `requestAbort`, `finishRun`, `releaseRun`, `findResumableRuns`, `markStaleRunsInterrupted`, `getLeaseTtlMs`, `getHeartbeatIntervalMs` |
| **Checkpoints** | `saveCheckpoint({ runId, snapshot })`, `loadCheckpoint(runId)` |
