`@riavzon/ai` supports both stateless turns (where your app passes `history`) and persisted multi-turn conversations backed by the `conversations` and `messages` tables. When a thread grows long, rolling compaction folds older messages into a summary stored on the conversation row while keeping the newest exchanges verbatim.

## Persist conversations with `createAgent()`

Add `conversation: { persist: true }` to `createAgent()` and supply `userId` on every turn. Omit `conversationId` on the first turn to create a new conversation; pass the returned `conversationId` on follow-up turns to continue the thread.

```ts [src/conversations.ts]
import { createAgent } from "@riavzon/ai";

const agent = await createAgent({
  model: { model: "gpt-4o-mini" },
  systemInstructions: "You remember earlier details in this conversation.",
  conversation: { persist: true },
});

// Turn 1: creates a new conversation titled from the first message
const first = await agent.complete({
  userId: "user_42",
  message: "Our deployment region is eu-central-1.",
});

// Turn 2: loads history automatically and appends the new exchange
const second = await agent.complete({
  userId: "user_42",
  conversationId: first.conversationId,
  message: "Which region did I say we deploy to?",
});

console.log(second.text);
```

### How stored tool traces replay across turns

When an assistant turn calls tools, `@riavzon/ai` saves the unredacted tool steps in `messages.trace`. On subsequent turns, `historyToMessages()` expands each traced assistant turn back into real OpenAI protocol messages (`assistant` with `tool_calls`, followed by `tool` role results, followed by the final `assistant` reply). The model sees the real tool outputs from earlier turns instead of guessing or re-running expensive tools.

## Enable rolling compaction

Long conversations eventually increase prefill latency and approach context limits. Configure `compaction` on `AgentConfig` to fold old messages into a rolling summary once estimated history tokens cross `tokenThreshold`.

```ts [src/compacted-agent.ts]
import { createAgent } from "@riavzon/ai";

const agent = await createAgent({
  model: { model: "gpt-4o-mini" },
  systemInstructions: "You are an ongoing project assistant.",
  conversation: { persist: true },
  compaction: {
    temperature: 0.2,
    maxTokens: 1024,
    tokenThreshold: 12_000,
    keepRecentMessages: 20,
    reserveTokens: 2048,
    attempts: 2,
  },
});
```

::field-group
:::field{name="temperature" type="number" required}
Sampling temperature for the summarization call (keep low, such as `0.1` to `0.3`).
:::

:::field{name="maxTokens" type="number" required}
Maximum token budget for the generated summary.
:::

:::field{name="tokenThreshold" type="number" required}
Estimated token count over the existing summary plus all uncompacted messages above which older turns are folded. The system prompt and incoming user message are not counted in this estimate; account for them in `reserveTokens`.
:::

:::field{name="keepRecentMessages" type="number" required}
Number of newest stored messages to keep verbatim after the summary (for example, `20` preserves the last 10 user/assistant exchanges).
:::

:::field{name="reserveTokens" type="number"}
Optional extra headroom subtracted from `tokenThreshold` to leave space for the system prompt, tool results during the loop, and the final answer.
:::

:::field{name="attempts" type="number" default="2"}
Write retry attempts when persisting the updated summary watermark to the `conversations` table. Persistence failure is logged and never fails the user's turn.
:::
::

### How the compaction watermark works

Each `conversations` row stores two columns: `compacted_summary` and `compacted_through_message_id`.

1. On each turn, `@riavzon/ai` selects all messages with `id > compacted_through_message_id` and estimates total tokens across the existing summary plus those messages.
2. If estimated tokens stay below `tokenThreshold - (reserveTokens ?? 0)`, no summarization call runs.
3. If the budget is exceeded and older messages exist outside the `keepRecentMessages` tail, the runtime summarizes the prior summary together with the older slice and advances `compacted_through_message_id` to the last folded message ID.
4. The summary is injected as a single system note (`[System Note: Earlier conversation summary: ...]`) followed by the verbatim recent turns.

::note
Compaction requires `conversation` to be configured on `createAgent()`. Attempting to set `compaction` on a stateless agent throws at agent construction.
::

## Stateless agents with manual history

When your application manages its own conversation storage, omit `conversation` from `createAgent()` and supply `history` on each turn.

```ts [src/stateless-agent.ts]
import { createAgent, type HistoryMessage } from "@riavzon/ai";

const agent = await createAgent({
  model: { model: "gpt-4o-mini" },
  systemInstructions: "You are a helpful coding assistant.",
});

const history: HistoryMessage[] = [
  { id: 1, role: "user", message: "We use Kysely with PostgreSQL." },
  {
    id: 2,
    role: "assistant",
    message: "Got it — I will tailor examples to Kysely and PostgreSQL.",
  },
];

const result = await agent.complete({
  message: "Show me how to select the latest 10 rows.",
  history,
});
```

## Using low-level conversation & compaction primitives

Custom AI clients that bypass `createAgent()` can call the exact same building blocks directly:

- `resolveConversation(userId, conversationId, firstMessage)` loads an existing conversation (with its history and `CompactionState`) or creates a new one.
- `historyToMessages(message)` converts one `HistoryMessage` (including its `trace.steps`) into OpenAI `ChatCompletionMessageParam[]`.
- `compactHistory(history, state, compaction, summarize)` computes the prompt message list and returns `{ messages, estimatedTokens, update }`.
- `makeCompactionHandler(convId, { attempts })` builds a non-throwing persistence callback that retries `saveConversationCompaction()`.

```ts [src/custom-compaction.ts]
import {
  aiClients,
  compactHistory,
  EMPTY_COMPACTION_STATE,
  makeCompactionHandler,
  resolveConversation,
} from "@riavzon/ai";

export async function buildTurnMessages(
  userId: string,
  conversationId: number | undefined,
  userMessage: string,
) {
  const resolved = await resolveConversation(
    userId,
    conversationId,
    userMessage,
  );
  if (!resolved.ok) {
    throw new Error(resolved.reason);
  }

  const client = aiClients();
  const saveCompaction = makeCompactionHandler(resolved.id, { attempts: 2 });

  const outcome = await compactHistory(
    resolved.history,
    resolved.compaction ?? EMPTY_COMPACTION_STATE,
    {
      temperature: 0.2,
      maxTokens: 1024,
      tokenThreshold: 12_000,
      keepRecentMessages: 20,
      reserveTokens: 2048,
    },
    async (prompt) => {
      const completion = await client.chat.completions.create({
        model: "gpt-4o-mini",
        temperature: 0.2,
        max_tokens: 1024,
        messages: [{ role: "user", content: prompt }],
      });
      return completion.choices[0]?.message?.content ?? "";
    },
  );

  if (outcome.update.changed) {
    await saveCompaction(outcome.update);
  }

  return {
    conversationId: resolved.id,
    messages: [
      ...outcome.messages,
      { role: "user" as const, content: userMessage },
    ],
  };
}
```
