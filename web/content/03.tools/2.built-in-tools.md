`@riavzon/ai` ships eight production-ready built-in tools. Enable them by name inside `createAgent({ tools: { common: [...] } })`, resolve them into `ToolSpec[]` with `resolveCommonTools()`, or invoke any individual handler factory directly inside your own AI client.

## Catalog of built-in tools

| Name (`CommonToolName`)     | Optional peer(s)                         | Default cache                                                                | Default concurrency | Default SSE `emitResult` | Notes                                                                                                        |
| --------------------------- | ---------------------------------------- | ---------------------------------------------------------------------------- | ------------------- | ------------------------ | ------------------------------------------------------------------------------------------------------------ |
| `calculator`                | `mathjs`                                 | None                                                                         | Unbounded           | `"preview"`              | Evaluates arithmetic and scientific expressions safely via `mathjs`.                                         |
| `get_current_datetime`      | None                                     | None                                                                         | Unbounded           | `"preview"`              | Returns UTC ISO timestamp and formatted local time for a validated IANA timezone (`validTimezone()`).        |
| `currencies_convertor`      | `easy-currencies`                        | `21600s` (6h), global                                                        | Unbounded           | `"preview"`              | Converts an amount between 3-letter ISO currency codes.                                                      |
| `search_db`                 | None                                     | `3600s` (1h), global                                                         | Unbounded           | `"none"`                 | Vector similarity search across indexed `document_chunks`.                                                   |
| `get_document`              | None                                     | `3600s` (1h), scoped per `userId`                                            | Unbounded           | `"none"`                 | Reads full or paginated chunk windows (up to 10 chunks per call) of a user-owned document.                   |
| `extractor` | `@steipete/summarize-core` | Built-in extractor cache (`EXTRACTOR_CACHE_TTL_SECONDS`, default `86400s`) | `3` | `"none"` | Extracts and sanitizes Markdown (and media transcripts) from URLs. |
| `pdf_creator`               | `pdf-lib`, `@pdf-lib/fontkit`, `ioredis` | Content-addressed Redis entry (`AGENT_GENERATED_FILE_TTL`, default `86400s`) | `2`                 | `"preview"`              | Creates or modifies PDFs with text, images, rectangles, SVG paths, and Unicode DejaVu fonts. | `create_styled_spreadsheet` | `exceljs`, `ioredis`                     | Content-addressed Redis entry (`AGENT_GENERATED_FILE_TTL`, default `86400s`) | `2`                 | `"preview"`              | Generates styled XLSX or CSV files from JSON rows. Requires Redis.                                           |

## Enable and override defaults

Pass bare tool names to use the package defaults, or pass a `CommonToolEntry` object to customize `cache`, `maxCalls`, `concurrency`, `stream`, or `make`.

```ts [src/common-tools.ts]
import {
  createAgent,
  createStyledSpreadsheet,
  extractor,
  getDocument,
  pdfCreator,
  searchDb,
} from "@riavzon/ai";

export const agent = await createAgent({
  model: { model: "gpt-4o-mini" },
  systemInstructions: "Help the user research documents and export reports.",
  conversation: { persist: true },
  tools: {
    common: [
      "calculator",
      "get_current_datetime",
      "currencies_convertor",
      // Scope vector search strictly to the requesting user
      {
        name: "search_db",
        cache: { ttl: 1800, scoped: true },
        make: (ctx) => searchDb(ctx.userId),
      },
      // Tune token caps for document paging
      {
        name: "get_document",
        maxCalls: 6,
        make: (ctx) =>
          getDocument(ctx.userId, {
            maxDocTokens: 4000,
            chunkTokenCap: 1200,
            maxChunksPerRead: 10,
          }),
      },
      // Cap extracted page output tokens
      {
        name: "extractor",
        concurrency: 2,
        make: () => extractor(true, 25_000, 86_400),
      },
      // Mount generated download links under your custom route prefix
      {
        name: "pdf_creator",
        make: () => pdfCreator("/v1/downloads"),
      },
      {
        name: "create_styled_spreadsheet",
        make: () => createStyledSpreadsheet("/v1/downloads"),
      },
    ],
  },
});
```

::tip
By default, `search_db` searches across all stored documents (ideal for shared knowledge bases). For multi-tenant apps where each user owns private documents, override `search_db` with `make: (ctx) => searchDb(ctx.userId)` and set `cache: { ttl: 3600, scoped: true }`.
::

## Serve generated PDF and spreadsheet downloads

When `pdf_creator` or `create_styled_spreadsheet` runs, it hashes the validated arguments into a deterministic `fileId`, stores the generated file in Redis for `AGENT_GENERATED_FILE_TTL` seconds (default `86400`), and returns a download link under your configured `downloadPath` (default `"/api/files"`).

Use `readGeneratedFile()` in your HTTP download route to serve the file with ready-made headers:

```ts [src/routes/files.ts]
import { readGeneratedFile } from "@riavzon/ai";

export async function GET(fileId: string): Promise<Response> {
  const outcome = await readGeneratedFile(fileId);
  if (!outcome.ok) {
    const status = outcome.reason === "not_found" ? 404 : 500;
    return new Response(outcome.message, { status });
  }

  return new Response(new Uint8Array(outcome.file.buffer), {
    headers: outcome.file.headers,
  });
}
```

::warning
Both `pdfCreator()` and `createStyledSpreadsheet()` require an `ioredis` client in `configuration({ redis })`. With the default `"memory"` store they return `toolError("TOOL_DISABLED", "This tool is currently not available")`.
::

## Configure the `extractor` tool

The `extractor` tool relies on `@steipete/summarize-core` and reads optional settings from `configuration({ extractor: { ... } })`:

- `extractor.timeoutMs` (default `120000`), `extractor.deadlineMs` (default `0`), `extractor.minContentCharacters` (default `80`), and `extractor.maxCharacters` (default `Infinity`).
- Optional local media binaries: `ytDlpBin`, `whisperCppBin`, `whisperCppModelPath`, `disableLocalWhisper`.

### Configure timeouts, failure handling, and caching

- **Two distinct timeouts**:
  - `extractor.timeoutMs` _(default `120000` ms)_: per-request fetch timeout when retrieving a page or media source.
  - `extractor.deadlineMs` _(default `0`, disabled)_: total wall-clock budget for extracting one URL, including fetching, parsing, and media transcription. Set a positive limit (such as `25_000`) when latency matters more than waiting on slow pages or long videos.
- **Per-URL failure isolation**: Non-HTML binary files (PDFs, images, archives), pages shorter than `minContentCharacters`, and timed-out URLs fail individually instead of failing the whole batch. Failed URLs return `{ url, error: "No usable markdown was extracted." }` inside `results`, so other extracted pages still reach the model.
- **Markdown sanitization**: Before returning page text to the model, `extractor` strips inline images, turns Markdown links into plain label text, removes embedded base64 data URIs and raw URLs, and collapses excess blank lines.
- **Separate capped and full caches**: Token-capped (`limitDataTokens: true`) and full-text (`limitDataTokens: false`) calls use separate cache namespaces so they never overwrite each other.
- **Works in memory and with Redis**: Unlike `pdf_creator` and `create_styled_spreadsheet` (which require Redis), `extractor` works with both the default in-memory cache and an `ioredis` client.

::note
**What built-in tools send to the model.**

- **No hidden prompts or secondary LLM calls:** None of the eight built-in tools inject `system` messages or call an LLM on their own. The built-in `extractor()` tool does **not** run LLM summarization — the `extractor.llm*` configuration options apply only when you call `summarizeWithLlm()` or `withLlmSummary()` directly (see [Extract and summarize URLs directly](#extract-and-summarize-urls-directly)).
- **Truncation marker:** When `limitDataTokens` is `true` and a page exceeds `EXTRACTOR_MAX_CONTENT_TOKENS` (default `50000`), `extractor` appends `\n\n[...Content truncated due to length limits...]`.
- **Tool descriptions:** All guidance for built-in tools lives in their function descriptions (for example, `get_document` instructs the model to page in slices of up to 10 chunks using `nextChunkStart`, and `search_db` guides the model to follow up with `get_document` for full documents).
::

```ts [src/extractor-factory.ts]
import { extractor } from "@riavzon/ai";

// extractor(limitDataTokens, maxContentTokens?, cacheTtlSeconds?, formatter?)
const handler = extractor(
  true,
  30_000,
  86_400,
  (title, rawText) => `# ${title}\n\n${rawText}`,
);
```

## Extract and summarize URLs directly

To extract web pages or summarize content outside an agent tool call, use the four standalone helpers backed by optional peer `@steipete/summarize-core`:

- `extractWithSummarize(url, options?)` — Extracts Markdown (or a media transcript) and page metadata for a single URL.
- `extractManyWithSummarize(urls, options?)` — Extracts multiple URLs concurrently and collects per-URL results so one failing URL never aborts the batch.
- `summarizeWithLlm(extraction, log, options?)` — Summarizes extracted text with your configured OpenAI client when the body exceeds the character threshold.
- `withLlmSummary(extraction, log, options?)` — Wraps `summarizeWithLlm()` and returns a copy of the extraction with `content` and `characters` replaced by the summary, plus the full summary metadata under `summary`.

Unlike the built-in `extractor()` tool, `extractWithSummarize()` and `extractManyWithSummarize()` return the raw extracted text directly without Markdown sanitization, token truncation, or caching.

```ts [src/url-summarize.ts]
import {
  extractManyWithSummarize,
  extractWithSummarize,
  getConfiguration,
  summarizeWithLlm,
  withLlmSummary,
} from "@riavzon/ai";

const { logger } = getConfiguration();

// 1. Extract a single URL and summarize it in place
const page = await extractWithSummarize("https://example.com/article", {
  minCharacters: 120,
  deadlineMs: 25_000,
});

const condensed = await withLlmSummary(page, logger, {
  model: "gpt-4o-mini",
  length: "medium",
  minCharactersToSummarize: 4_000,
  promptOverride: "Focus on pricing and architecture limits.",
});

console.log(condensed.title, condensed.summary.passthrough, condensed.content);

// 2. Extract a batch with per-URL failure isolation
const outcomes = await extractManyWithSummarize([
  "https://example.com/a",
  "https://example.com/b",
]);

for (const outcome of outcomes) {
  if (!outcome.ok) {
    logger.warn({ url: outcome.url, err: outcome.error }, "Extraction failed");
    continue;
  }

  const summary = await summarizeWithLlm(outcome.value, logger);
  console.log(outcome.url, summary.length, summary.summary);
}
```

### Extraction defaults and rejection behavior

`extractWithSummarize()` and `extractManyWithSummarize()` inherit defaults from `configuration({ extractor })` and accept per-call overrides via `ExtractOptions`:

- **`minCharacters`**: defaults to `extractor.minContentCharacters` (`80`).
- **`deadlineMs`**: defaults to `extractor.deadlineMs` (`0`, no wall-clock deadline).
- **`timeoutMs`**: defaults to `extractor.timeoutMs` (`120_000` ms).
- **`maxCharacters`**: defaults to `extractor.maxCharacters` (`Infinity`).
- **Media transcription**: uses any local binary paths configured in `configuration({ extractor })` (`ytDlpBin`, `whisperCppBin`, `whisperCppModelPath`, `disableLocalWhisper`).
- **Content format**: extracts readable Markdown by default, automatically fetches YouTube or media transcripts without timestamps when available, and rejects non-HTML asset payloads. When a URL yields both page text and a transcript, `@riavzon/ai` keeps the longer body and sets `fromTranscript: true` if the transcript wins.

`extractWithSummarize()` rejects when a URL exceeds `deadlineMs`, returns a non-HTML binary file (such as a PDF, image, or archive), yields fewer than `minCharacters` characters, or fails to fetch. `extractManyWithSummarize()` catches each failure and returns `{ url, ok: false, error }` for that entry.

### Summarize extracted content with an LLM

`summarizeWithLlm()` (and `withLlmSummary()`, which wraps it) resolves its settings from per-call options first, falling back to `configuration({ extractor })` and built-in defaults:

- **Model**: uses `options.model`, or falls back to `extractor.llmModel`. Throws an error if neither is configured.
- **Character threshold**: uses `options.minCharactersToSummarize`, then `extractor.llmMinCharacters`, defaulting to `4_000` characters.
- **Length preset**: uses `options.length`, then `extractor.llmLength`, defaulting to `"medium"` (`"short"`, `"medium"`, `"long"`, `"xl"`, or `"xxl"`).
- **Temperature**: uses `extractor.llmTemperature`, defaulting to `0.2`.

Edge cases are handled automatically:

- **Blank content**: throws immediately when the extracted body is empty or whitespace-only.
- **Short-body passthrough**: skips the model call when the body is shorter than the character threshold, returning the original text with `passthrough: true`.
- **Empty model reply**: logs a warning and falls back to the original text with `passthrough: true` if the model returns blank output.

::note
When the extracted text meets the character threshold, `summarizeWithLlm()` sends a single completion request to your configured OpenAI client using the resolved temperature and a token limit matched to the chosen length preset. The request includes a built-in summarization system prompt plus a user prompt containing the page metadata (URL, title, site name, description), extracted text, transcript/truncation flags, target length, and your optional `promptOverride`.
::

## Tool error envelopes & `maxCalls` budget messages

All built-in tools — and the tool middleware wrapping them — communicate failures and budget caps back to the model as `{ role: "tool" }` JSON strings in `{"error":{"code":"...","message":"..."}}` format (`toolError(code, message)`). Knowing these exact messages avoids surprises when debugging model behavior.

### `maxCalls` budget-exceeded messages

- **Per-tool `maxCalls` cap (`CommonToolEntry.maxCalls` via `limitTool()`):** Once a built-in tool reaches its per-tool cap, the handler stops running and returns this steering message to the model:

```json [Exact tool-role message when CommonToolEntry.maxCalls is reached]
{
  "error": {
    "code": "TOOL_LIMIT_REACHED",
    "message": "<toolName> has been called <max> times already. Do not call it again — synthesize the final answer from the results you already have."
  }
}
```

- **Global `model.tools.maxCalls` cap (`executeToolLoop()`):** If the model requests more calls in one round than remain in the global turn budget, unexecuted calls receive:

```json [Exact tool-role message for skipped calls past model.tools.maxCalls]
{
  "error": {
    "code": "CALL_LIMIT_EXCEEDED",
    "message": "Budget exhausted; this call was not executed."
  }
}
```

When either `model.tools.maxRounds` or `model.tools.maxCalls` is exhausted, `executeToolLoop()` also appends a trailing synthesis `{ role: "system" }` prompt with `tool_choice: "none"` (see [Injected prompts and error messages](/tools/tool-loop#injected-prompts-and-error-messages)).

### Built-in tool error envelopes (`toolError()`)

| Built-in tool                               | Error code(s)                                                                  | Message sent to the model                                                                                                          |
| ------------------------------------------- | ------------------------------------------------------------------------------ | ---------------------------------------------------------------------------------------------------------------------------------- |
| `calculator`                                | `INVALID_EXPRESSION`, `MATH_EVALUATION_FAILED`                                 | `"Expression must be a string."` or the `mathjs` evaluation error message.                                                         |
| `get_current_datetime`                      | `VALIDATION_ERROR`                                                             | `"Provide a valid IANA timezone."`                                                                                                 |
| `currencies_convertor`                      | `VALIDATION_ERROR`, `CONVERSION_FAILED`                                        | Zod issues JSON, or `"Unable to convert currencies. Check if the currency codes are valid."`                                       |
| `search_db`                                 | `VALIDATION_ERROR`, `DB_SEARCH_FAILED`                                         | Zod issues JSON, or `"Database search failed or returned an invalid response."`                                                    |
| `get_document`                              | `VALIDATION_ERROR`, `NOT_FOUND`, `DOCUMENT_FAILED`                             | Zod issues JSON, `"Supply both inclusive chunk indexes, selecting at most <maxChunksPerRead> chunks."`, `"Document not found or access denied."`, or `"Unable to retrieve document."` |
| `extractor`                                 | `VALIDATION_ERROR`, `EXTRACTION_FAILED`                                        | Zod issues JSON, or `"Unable to extract page content."` (individual failed URLs return `{ url, error: "No usable markdown was extracted." }`). |
| `pdf_creator`                               | `TOOL_DISABLED`, `VALIDATION_ERROR`, `PDF_CREATION_FAILED`                     | `"This tool is currently not available"` (with `"memory"` store), Zod issues JSON, or the PDF generation error message.            |
| `create_styled_spreadsheet`                 | `TOOL_DISABLED`, `VALIDATION_ERROR`, `SPREADSHEET_CREATION_FAILED`             | `"This tool is currently not available"` (with `"memory"` store), Zod issues JSON, or the spreadsheet generation error message.    |

## Use built-in tools outside `createAgent()`

Every built-in tool's OpenAI function schema, Zod parameter schema, and factory function is exported directly from `"@riavzon/ai"`:

- **Factory functions**: `calculator()`, `getCurrentDatetime()`, `currenciesConvertor()`, `searchDb(userId?)`, `getDocument(userId, options?)`, `extractor(limitDataTokens, ...)`, `pdfCreator(downloadPath?)`, `createStyledSpreadsheet(downloadPath?)`.
- **Zod parameter schemas**: `currencyParams`, `documentParams`, `pdfCreatorParams`, `spreadsheetCreatorParams`, `searchParams`.
- **Helpers**: `resolveCommonTools(tools)`, `buildToolDefinitions({ enabled, extra })`, `validTimezone(tz)`, `extractWithSummarize(url, options?)`, `extractManyWithSummarize(urls, options?)`, `summarizeWithLlm(extraction, log, options?)`, `withLlmSummary(extraction, log, options?)`.

```ts [src/manual-common-tools.ts]
import {
  buildToolDefinitions,
  buildToolRegistry,
  resolveCommonTools,
} from "@riavzon/ai";

// Option A: Resolve full ToolSpec[] with built-in defaults & policies
const specs = resolveCommonTools(["calculator", "get_current_datetime"]);
const registry = buildToolRegistry({ userId: "u_1" }, specs);

// Option B: Build only OpenAI ChatCompletionTool[] definitions
const definitions = buildToolDefinitions({
  enabled: ["calculator", "currencies_convertor"],
});
```
