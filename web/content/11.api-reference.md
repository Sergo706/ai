Every symbol below is exported directly from the root package `"@riavzon/ai"`. Subpath imports are not used — import high-level abstractions and low-level primitives from the same entry point.

Before calling any runtime API, initialize the library once at startup by running [`configuration()`](#configuration) — see the [Configuration guide](/configuration) for database, OpenAI client, embedding, cache, and run-system setup.

```ts [Single Entry Point]
import {
  configuration,
  createAgent,
  executeToolLoop,
  AgenticWorkflowLoop,
  startRuns,
} from "@riavzon/ai";
```

## Agents

High-level agent factory and turn configuration. See the [Agents guide](/agents).

### `createAgent`

Builds one reusable agent. See [Agents](/agents).

```ts

  config: AgentConfig<TMeta>,

```

| Parameter | Type | Description |
| --- | --- | --- |
| `config` | `AgentConfig<TMeta>` | The agent's identity, model, tools and optional subsystems. |

### Agent types

#### `Agent`

One reusable agent.

```ts
interface Agent<TMeta = unknown> {
  chat<S extends z.ZodType = z.ZodNever>(
    input: JsonChatInput<TMeta, S>,

  complete<S extends z.ZodType = z.ZodNever>(
    input: JsonChatInput<TMeta, S>,

  close(): Promise<void>;
```

```ts
}
```

#### `ModelRequestOptions`

SDK options that describe *how* a request travels, not what it contains. Body, method, path, query, stream and signal are owned by the turn, so they are rejected here to keep a single place where each can be set.

```ts

  | "__security"
  | "__binaryResponse"

```

### `withToolCache`

Wrap a tool handler so repeated identical calls are served from the cache. Failed results are never cached, so a transient error is retried next time. See [Custom Tools](/tools/custom-tools).

```ts
function withToolCache(
  toolName: string,
  handler: ToolHandler,
  ttlSeconds = 3600,
  scopeKey = "global",
  normalizeArgs: (a: Record<string, unknown>) => Record<string, unknown> = (
    a,
  ) => a,
): ToolHandler
```

| Parameter | Type | Description |
| --- | --- | --- |
| `toolName` | `string` | Tool name, part of the cache key. |
| `handler` | `ToolHandler` | The handler to wrap. |
| `ttlSeconds` | `number` | Optional. Cache lifetime in seconds. Defaults to `3600`. |
| `scopeKey` | `string` | Optional. Extra key component, e.g. a user or tenant id. Defaults to `"global"`. |
| `normalizeArgs` | `(a: Record<string, unknown>) => Record<string, unknown>` | Optional. Drop or rewrite arguments that should not affect the key, e.g. a timestamp. Defaults to `(a) => a`. |

### `limitTool`

| Parameter | Type | Description |
| --- | --- | --- |

| `max` | `number` | Maximum number of allowed invocations for this tool within one request. |
| `handler` | `ToolHandler` | Underlying tool handler to wrap. |
| `toolCounts` | `Map<string, number>` | Mutable map counting calls per tool name across the request. |

### `extractor`

Builds the built-in `extractor` tool handler that crawls URLs, extracts and sanitizes Markdown, optionally truncates to a token cap, and caches results per URL in Redis or `MiniCache`. See [Built-In Tools](/tools/built-in-tools).

```ts
function extractor(
  limitDataTokens: boolean,
  EXTRACTOR_MAX_CONTENT_TOKENS = envInt(
    "EXTRACTOR_MAX_CONTENT_TOKENS",
    50_000,
    { min: 1000 },
  ),
  EXTRACTOR_CACHE_TTL_SECONDS = envInt("EXTRACTOR_CACHE_TTL_SECONDS", 86_400, {
    min: 0,
  }),
  formatter?: (
    title: string,
    rawText: string,
  ) => string,
): ToolHandler
```

| Parameter | Type | Description |
| --- | --- | --- |
| `limitDataTokens` | `boolean` | When `true`, trims extracted page text to `EXTRACTOR_MAX_CONTENT_TOKENS` and caches under the `ext:lim:` prefix; when `false`, keeps full text under `ext:full:`. |
| `EXTRACTOR_MAX_CONTENT_TOKENS` | `number` | Optional maximum token budget per extracted page when `limitDataTokens` is `true`. Defaults to `EXTRACTOR_MAX_CONTENT_TOKENS` env var or `50000` (min `1000`). |
| `EXTRACTOR_CACHE_TTL_SECONDS` | `number` | Optional per-URL cache TTL in seconds (`0` disables cache writes). Defaults to `EXTRACTOR_CACHE_TTL_SECONDS` env var or `86400`. |
| `formatter` | `(title: string, rawText: string) => string` | Optional post-processor receiving `(title, rawText)` to transform extracted text before token trimming and caching. |

### Tool argument schemas

#### `currencyParams`

Zod schema for `currency_converter` arguments: positive `amount` plus 3-letter uppercase ISO currency codes `from` and `to`.

#### `documentParams`

Zod schema for `get_document` arguments: positive integer `documentId` with optional zero-based `chunkStart` and `chunkEnd` bounds.

#### `pdfCreatorParams`

Zod schema for `pdf_creator` arguments: target `filename`, optional `basePdfBase64` template, and ordered `pages` operations.

#### `spreadsheetCreatorParams`

Zod schema for `spreadsheet_creator` arguments: `data` array of row records and optional `options` (`filename`, `sheetName`, `format`, styling).

## Workflow Agents

Budgeted multi-stage agentic workflow loop, serializable workflow state, and abort errors. See [Workflow Agents](/workflow-agents).

### `AgenticWorkflowLoop`

Runs a multi-stage research loop: seeds, local evidence, external discovery, critic, final answer. See [Workflow Agents](/workflow-agents).

```ts
class AgenticWorkflowLoop<TLocalItem, TDiscoveryPayload, TTarget, TExternalArtifact, TReport = undefined> {
```

| Parameter / Member | Type | Description |
| --- | --- | --- |

### `WorkflowState`

```ts

  externalArtifacts: TExternalArtifact[];
  errors: string[];
  criticNotes?: string;
  discoveryFailures: Map<string, number>;
  failedIntents: string[];
  seenLocalIds: Set<string | number>;
  attemptedTargets: Set<string>;
  stopReason: StopReason | undefined;
  constructor(initialQuery: string, budgets: WorkflowBudgets);
  markAborted(): void;
  toCheckpoint(): WorkflowStateSnapshot<TLocalItem, TExternalArtifact>;
  restore( snapshot: Partial<WorkflowStateSnapshot<TLocalItem, TExternalArtifact>>, ): void;
  appendEvidence(block: string): void;
  buildResult<TReport = undefined>( report?: TReport, ): WorkflowRunResult<TLocalItem, TExternalArtifact, TReport>;
}
```

| Parameter / Member | Type | Description |
| --- | --- | --- |
| `initialQuery` | `string` | Constructor argument seeding `pendingIntents` and `issuedIntents`. |

| `markAborted()` | `() => void` | Sets `stopReason = "aborted"`. |

```ts
function aiClients(type: "embedding" | "default" = "default"): OpenAI
```

| Parameter | Type | Description |
| --- | --- | --- |
| `type` | `"embedding" \| "default"` | Optional. `"embedding"` for the embeddings client, `"default"` for chat. Falls back to the chat client when no separate embeddings client is set. |

### `cacheGet`

Reads a cached value by key from Redis or the in-memory `MiniCache`, returning `null` on a miss or when no cache is configured. See [Configuration](/configuration).

```ts
function cacheGet<T>(key: string): Promise<T | null>
```

| Parameter | Type | Description |
| --- | --- | --- |
| `key` | `string` | Cache key. |

### `cacheGetMany`

Reads multiple cached string values in one batch (`MGET` on Redis or sequential lookups on `MiniCache`), preserving input key order with `null` for misses. See [Configuration](/configuration).

```ts
function cacheGetMany(
  keys: readonly string[],
): Promise<(string | null)[]>
```

| Parameter | Type | Description |
| --- | --- | --- |
| `keys` | `readonly string[]` | Keys to read. An empty array returns `[]` without a round trip. |

### `cacheSet`

Writes a string value to Redis or `MiniCache` with a millisecond TTL. No-op when caching is disabled. See [Configuration](/configuration).

```ts
function cacheSet(
  key: string,
  value: string,
  ttlMs: number,
): Promise<void>
```

| Parameter | Type | Description |
| --- | --- | --- |
| `key` | `string` | Cache key. |
| `value` | `string` | Value to store. |
| `ttlMs` | `number` | Lifetime in milliseconds. Rounded up to whole seconds on Redis, which cannot expire in fractions. |

### `cacheSetMany`

Writes multiple `{ key, value }` entries with a shared millisecond TTL using a Redis pipeline or `MiniCache`. See [Configuration](/configuration).

```ts
function cacheSetMany(
  entries: readonly { key: string; value: string }[],
  ttlMs: number,
): Promise<void>
```

| Parameter | Type | Description |
| --- | --- | --- |
| `entries` | `readonly { key: string; value: string }[]` | Key/value pairs to write. |
| `ttlMs` | `number` | Shared lifetime in milliseconds. |

### `consoleLogger`

A `Logger` that writes to `console`. Useful as a default and in tests; swap it for a real logger in production. See [Configuration](/configuration).

```ts
function consoleLogger(
  bindings: Record<string, unknown> = {},
): Logger
```

| Parameter | Type | Description |
| --- | --- | --- |
| `bindings` | `Record<string, unknown>` | Optional. Fields added to every line, e.g. `{ service: "api" }`. Defaults to `{}`. |

### Configuration types

#### `Logger`

The logger the package writes through. Any object with these five methods works; pass one to `configuration()`. A pino instance satisfies it as-is.

```ts
interface Logger {
  debug(obj: unknown, msg?: string): void;
  info(obj: unknown, msg?: string): void;
  warn(obj: unknown, msg?: string): void;
  error(obj: unknown, msg?: string): void;
  child(bindings: Record<string, unknown>): Logger;
}
```

#### `Configuration`

The configuration after defaults are applied.

```ts
type Configuration = z.infer<typeof configSchema>;
```

#### `ConfigurationInput`

The configuration you pass to `configuration()`. Every field except `db`, `openAiConfig` and `embeddingConfig` has a default, so a local setup can be as small as those three.

```ts
type ConfigurationInput = z.input<typeof configSchema>;
```
